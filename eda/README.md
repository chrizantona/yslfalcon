# EDA

Разведочный анализ данных задачи «Фалькон Тех» (ЛЦТ 2026): повторная идентификация автомобилей без номеров.

| Файл | Что внутри |
|---|---|
| `KEY_FINDINGS.md` | ключевые выводы и правила разработки — читать первым |
| `eda.ipynb` | ноутбук с результатами: 12 разделов, выводы после каждого |
| `eda.py` | исходник ноутбука в формате jupytext; править его, `.ipynb` собирается из него |
| `extract_features.py` | один проход по кадрам: статистики качества, эмбеддинги DINOv2 и CLIP для вырезок, эмбеддинг фона → `eda/cache/` |
| `run_eda.sh` | весь пайплайн: проверка и распаковка архива, извлечение признаков, сборка и запуск ноутбука |
| `requirements.txt` | версии пакетов, на которых ноутбук выполнялся |

## Как воспроизвести
1. Положить архив из личного кабинета в `BIG_DATA/dataset.zip` в корне репозитория.
2. Установить окружение и запустить пайплайн:

```bash
uv venv .venv --python 3.12
VIRTUAL_ENV=.venv uv pip install -r eda/requirements.txt
GPU=0 bash eda/run_eda.sh
```

`run_eda.sh` распаковывает архив в `/dev/shm/lct2026_dataset`, делает ссылку `BIG_DATA/dataset` и кладёт веса моделей в `hf/`. При первом запуске скачиваются веса DINOv2 и CLIP (≈ 1 ГБ). На одной H200 извлечение признаков заняло около минуты, выполнение ноутбука — около трёх.
