# Рабочее место «Фалькон»

React + TypeScript, Vite. Все шрифты и интерфейсные ресурсы находятся в репозитории;
браузер не обращается к внешним CDN. Полный запуск сервиса описан в `../README.md`.

```sh
npm ci
npm run dev
```

В разработке `/api` перенаправляется на `http://127.0.0.1:8000`.
Для другого адреса задайте `FALCON_API_URL`. Разрешённые Origin на сервере должны
включать адрес Vite. В Docker запросы идут через тот же Nginx, который отдаёт интерфейс.

```sh
npm test
npm run build
npm run format:check
```

## Устройство

- `api.ts` владеет HTTP-контрактом, cookie-сессией, CSRF, ошибками и загрузкой файлов.
- `hooks.ts` владеет обновлением ресурсов, безопасным объединением страниц и наблюдением за заданиями.
- `domain.ts` содержит независимые правила рамок, представления оценок и ссылок на выгрузки.
- `pages/` содержит шесть самостоятельных разделов. `components/` — редактор рамки,
  сравнение изображений и общие элементы интерфейса.
- `styles.css` определяет общую типографику, цветовые роли и адаптивную компоновку.

Отсутствующие данные отображаются явно. В текущей конфигурации подключена только
техническая заглушка: результаты не являются распознаванием автомобиля, оценки не
отображаются как проценты вероятности. Заключение оператора сохраняется отдельно.

При повторе неудавшегося поиска без изменения входных данных сохраняется один
Idempotency-Key. Активация галереи передаёт ожидаемую текущую версию. Асинхронные
ответы списка отбрасываются после обновления, а ранее открытые страницы сохраняются.

Тесты проверяют клиентский HTTP-контракт, CSRF, манифест, CAS, идемпотентность,
пагинацию, допустимость рамок и представление реальной карты чувствительности.
Это не замена проверке интерфейса в браузере.
