# Рабочее место «Фалькон»

React + TypeScript, Vite. Все шрифты и интерфейсные ресурсы находятся в репозитории;
браузер не обращается к внешним CDN. Полный запуск сервиса описан в `../README.md`.

```sh
npm ci
npm run dev
```

В разработке `/api` перенаправляется на `http://127.0.0.1:8000`.
Для другого адреса задайте `FALCON_API_URL`. Разрешённые Origin на сервере должны
включать адрес Vite. В Docker запросы идут через тот же Nginx, который отдаёт интерфейс.

```sh
npm test
npm run build
npm run format:check
```

## Устройство

- `api.ts` владеет HTTP-контрактом, cookie-сессией, CSRF, ошибками и загрузкой файлов.
- `hooks.ts` владеет обновлением ресурсов, безопасным объединением страниц и наблюдением за заданиями.
- `domain.ts` содержит независимые правила рамок, представления оценок и ссылок на выгрузки.
- `imports.ts` проверяет CSV, сопоставляет выбранные файлы и передаёт ограниченные по размеру части с учётом подтверждённого сервером прогресса.
- `pages/` содержит шесть самостоятельных разделов. `components/` — редактор рамки,
  сравнение изображений и общие элементы интерфейса.
- [UploadPrompt](src/components/UploadArtwork.tsx) объединяет оформление выбора изображений, каталогов и манифестов; камера с прозрачным экраном и стопка снимков с прозрачными окошками поставляются локальными PNG, CSV/JSON используют вектор документа. Иллюстрация реагирует на приближение мыши, сохраняя неподвижную область измерения. Источники — [UPLOAD_SOURCES.md](public/images/UPLOAD_SOURCES.md).
- [ResultsSurface](src/components/ResultsSurface.tsx) рисует декоративные точки за результатами: локальное увеличение у курсора затухает по гауссовой кривой. При отключённой анимации остаётся статический узор.
- [VehicleBackdrop](src/components/VehicleBackdrop.tsx) загружает локальную 3D-сцену отдельным модулем: одна размытая абстрактная машина, пауза, уменьшение движения и остановка в скрытой вкладке. `visuals/` содержит геометрию и жизненный цикл сцены. Предыдущий фон доступен по `/?backdrop=static`; точка сохранения — `43bdf85`.
- [CandidateCountWheel](src/components/CandidateCountWheel.tsx) выбирает top-N от 1 до 50 колесом, клавиатурой или кнопками; начальное значение 10. Сохранённый результат продолжает показывать исходный контекст поиска.
- `visuals/hoverTypewriter.ts` управляет эффектом набора на кликабельных элементах через делегирование событий и CSS Highlight; `typewriterClock.ts` гарантирует один активный текст и один таймер, сохраняя исходные DOM и значения полей.
- `PageHeading` задаёт общую иерархию всех шести разделов; поиск отдельно показывает подготовку, обработку и неизменяемый контекст сохранённого результата.
- `styles.css` определяет семантические цветовые токены, типографику и адаптивную компоновку. Интерфейс использует почти чёрный фон без разделительных линий, белый точечный узор результатов и монохромные действия; шрифты заказчика Unbounded и Manrope поставляются локально, IBM Plex Mono используется для кода и данных; правила и источники — в [DESIGN.md](../docs/DESIGN.md).

Браузер открывает сервис напрямую, без формы входа. При отсутствии сохранённой сессии
он один раз запрашивает локальное подключение; при ошибке появляется ручная кнопка
повтора. Параллельные обращения используют одну попытку подключения. Роли действий
по-прежнему определяет сервер.

Отсутствующие данные отображаются явно. В текущей конфигурации подключена только
техническая заглушка: результаты не являются распознаванием автомобиля, оценки не
отображаются как проценты вероятности. Заключение оператора сохраняется отдельно.

При повторе неудавшегося поиска без изменения входных данных сохраняется один
Idempotency-Key. Активация галереи передаёт ожидаемую текущую версию. Асинхронные
ответы списка отбрасываются после обновления, а ранее открытые страницы сохраняются.

Тесты проверяют клиентский HTTP-контракт, CSRF, манифест, CAS, идемпотентность,
пагинацию, допустимость рамок, представление реальной карты чувствительности,
CSV на 750 наблюдений, неоднозначные имена, размер частей, паузу и продолжение после потери ответа.
Это не замена проверке интерфейса в браузере.

## Полная галерея по CSV

В разделе «Галереи» выберите CSV с колонками `image_id,x,y,w,h` и папку изображений
или несколько файлов. `image_id` сопоставляется с именем файла либо именем без расширения;
одному наблюдению соответствует один файл. Дополнительные изображения из выбранной
папки не отправляются. Предварительная проверка показывает отсутствующие файлы,
неоднозначные имена, некорректные рамки и превышение размера. Сервер дополнительно
проверяет содержимое каждого изображения и пересечение BBox с кадром.

Загрузка идёт ограниченными частями. После перезагрузки страницы выберите загрузку
в списке сохранённых и снова укажите ту же папку: браузер не сохраняет доступ к локальным
файлам, а приложение пропускает уже принятые сервером изображения. При потере ответа
повтор сначала перечитывает состояние сессии. Пауза действует после текущей части.

Когда приняты все файлы, нажмите «Подготовить новую версию». Только это действие создаёт
одну полную версию; каждая часть не становится отдельной галереей. Затем явно активируйте
готовую версию в таблице. Подготовка использует техническую заглушку, а не ReID-модель.
Небольшой импорт изображений с необязательным JSON-манифестом оставлен в раскрываемом блоке.
