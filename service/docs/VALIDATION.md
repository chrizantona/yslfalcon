## Автономный комплект и изоляция сети

Упаковщик собрал комплект Linux/amd64 с исходниками, тремя Docker-образами и manifest. Проверены SHA-256 **121 файла**, архитектуры и ID образов. Рабочие секреты, базы, загруженные изображения и обученные веса в комплект не входят.

На новом проекте с отдельными volume и портом 18091 выполнены загрузка архива образов и запуск с `--no-build --pull never`. Доступность HTTP-ресурсов, шрифтов, документации и OpenAPI проверена и на этой установке.

Затем у тестового Nginx отключили дополнительную ingress-сеть. Инспекция подтвердила: все пять контейнеров подключены только к одной сети с `Internal=true`. Из Python-клиента внутри API, обращавшегося к `http://web:8080`, **повторно прошли оба smoke-сценария, включая 750 изображений**. Внешнее TCP-соединение из API и runtime завершилось `errno 101` (сеть недоступна); `wget` из web также сообщил `Network unreachable`.

Это проверка полностью изолированного тестового стека. В обычном комплекте Nginx дополнительно подключён к ingress для публикации порта на loopback; API, worker, runtime и БД остаются во внутренней сети. Физическое отключение сети компьютера не выполнялось. Сборка amd64 под эмуляцией не является замером производительности целевого CPU или GPU.

## Команды для повторения

Из `service/`, после установки зависимостей и запуска отдельного тестового стека:

```bash
.venv/bin/python -m pytest -q
.venv/bin/ruff check backend tests scripts
.venv/bin/ruff format --check backend tests scripts
npm --prefix frontend test
npm --prefix frontend run build
npm --prefix frontend run format:check
docker compose config --quiet
.venv/bin/python scripts/smoke.py --url http://127.0.0.1:18090 --token-file .local/access-token.txt
.venv/bin/python scripts/smoke_gallery.py --url http://127.0.0.1:18090 --token-file .local/access-token.txt
```

URL и файл токена должны относиться к выбранной тестовой установке. Smoke-сценарии создают новые синтетические QA-галереи. Команды сборки и запуска автономного комплекта приведены в [README](../README.md#автономная-поставка); его целостность проверяет `python3 scripts/verify_bundle.py delivery/falcon-offline`.
