Дата: 21 сентября 2026. Среда: macOS arm64, Docker Desktop, Linux-контейнеры, Python 3.13, Node 22+. Проверки относятся к новому `service/`; обученная ReID-модель намеренно не подключалась.

## Реальный стек

Собраны образы приложения и интерфейса. `web`, `api`, `worker`, `runtime` и PostgreSQL проходят healthcheck. HTTP smoke выполняется через Nginx и PostgreSQL на отдельном проекте Compose с синтетическими QA-изображениями.

Проверенный сценарий: создать галерею → импортировать изображения → дождаться задания → активировать версию → выполнить поиск с BBox → повторить с тем же ключом → сохранить заключение → рассчитать карту → скачать PDF/JSON/CSV → создать и активировать другую версию → воспроизвести поиск на прежней версии. Проверено, что неавторизованный клиент не получает изображения, а заглушка не возвращает принятых кандидатов.

Отдельный HTTP-прогон проверил доступность собранных JS/CSS и обоих локальных шрифтов, защитные заголовки Nginx, HttpOnly сессию, запрет изменения без CSRF и завершение сессии. OpenAPI объявляет bearer или cookie для защищённых методов; вход и health публичны.

Финальный русский PDF из работающего стека отрисован Poppler и визуально проверен на обеих страницах: фотографии, кириллица, подписи, предупреждение о заглушке, заключение и контрольные суммы читаются без перекрытий и обрезки. В финальном HTTP-прогоне PDF занимал 34 513 байт; JSON — 3 734, CSV — 519. Размеры относятся к синтетическому набору из двух кандидатов.

## Ревью

Независимое ревью выявило и закрыло гонки владения фоновым заданием, активации версии, пагинации и сохранения заключений; исправлены транспорт manifest, повторы поиска, отображение прогресса и схема авторизации OpenAPI. Финальное ревью исходников не оставило замечаний категорий Critical/Important в проверенном объёме.

## Автономный комплект

`package_offline.py` собрал исходники и архив трёх Docker-образов. `verify_bundle.py` проверил SHA-256 для 105 файлов комплекта. Секреты, рабочие базы, загруженные изображения и веса в исходную поставку не попали.

Скрипт комплекта успешно выполнил загрузку локальных образов и запуск с `--no-build --pull never` в отдельном проекте `yslfalcon-offline-check`, с новой базой, отдельными volume и портом 18090. На этом экземпляре повторно прошёл полный HTTP smoke с тремя экспортами и воспроизведением прежней версии. Проверены локальные образы arm64; сеть компьютера физически не отключалась. Запуск на Linux x86_64 требует соответствующих образов и отдельной проверки.

## Границы доказательств

- Браузер в этой сессии недоступен: обнаружение вернуло пустой список. Скриншоты интерфейса, реальные клики, фокус и адаптивность визуально не проверены. Сборка и HTTP-проверки не заменяют эту приёмку.
- Тесты заглушки не измеряют ReID, mAP, F1, TNR, качество отказа или GPU-производительность. Конкурсная готовность модели не заявляется.
- Масштаб в миллион наблюдений, отказ узла, восстановление резервной копии и обновление схемы не проверены. Ограничения описаны в [IMPLEMENTATION](IMPLEMENTATION.md).
- GitHub Actions подготовлен, но удалённый CI в рамках этой работы не запускался. Публичная публикация сервиса не выполнялась.
