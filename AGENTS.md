# Правила для агентов

Проект: сервис повторной идентификации автомобилей без номеров («Фалькон Тех», ЛЦТ 2026).
Перед изменениями в загрузке данных, валидации, обучении или сабмите прочитай `eda/KEY_FINDINGS.md`: там цифры, обоснования и код протокола.

## Обязательно
- Делить train только по `vehicle_id`. Валидировать на псевдо-тесте `make_pseudo_test` (gallery = один кадр на пару «машина + камера», query = остальные кадры) и перемешивать строки.
- Считать mAP, R1, R5 и mINP по протоколу `reid_eval`: совпадения «та же машина + та же камера» исключены.
- Порог отказа калибровать на псевдо-тесте, из gallery которого убраны кадры 30% машин, по нормированному score, а не по сырому косинусу.
- Держать суммарный размер весов ≤ 2 ГБ и следить за временем инференса на батче 1.
- `embeddings.npy`: сначала все query в порядке `test_query.csv`, затем все gallery в порядке `test_gallery.csv`.

## Запрещено
- Использовать номерные знаки или их остатки: дисквалификация.
- Использовать порядок строк CSV, `image_id`, md5 файлов или продублированные кадры как признак, фильтр или тай-брейк.
- Использовать `camera_id` на инференсе, а id камер, выведенные по фону, — без разрешения организаторов.
- Коммитить данные, веса и кэш: `BIG_DATA/`, `hf/`, `eda/cache/`.
