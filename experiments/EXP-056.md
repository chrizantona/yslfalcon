# EXP-056 · CLIP-SENet после VehicleID на наших фолдах

## Идея
- **Родитель:** EXP-055 (тег `exp-055`) — CLIP-SENet после VehicleID.
- **Изменение (одно):** обучение на наших фолдах 1–3 от чекпоинта EXP-055 (всё, кроме классификатора) тем же рецептом статьи.
- **Гипотеза:** см. EXP-055; ожидаем заметно ниже EXP-054 (0,8939).
- **Пакет изменений:** нет.

## Запуск
- **Тег:** `exp-056` · дифф с родителем: `git diff exp-055 exp-056`
- **Внешние веса и данные:** как у EXP-055; старт — `136a8ea131cb4019a68605cbae11ae5f.pt`.
- **Рецепт:** как у EXP-055, но 120 эпох (каждая машина один раз, 924 машины → 57 шагов), разогрев 10, вехи 40 и 70 — расписание статьи.
- **Потоковость:** да.
- **Конфиг:** `configs/exp056_clip_senet_init_exp055.yaml`
- **Команда:** очередь `scripts/queues/pod_a_clip_senet.txt` после EXP-055.
- **Протокол:** `configs/val_v2.yaml`, фолд 0; обучение на фолдах 1–3; фолд 4 не трогается.
- **Сиды:** 0, 1, 2.
- **Окружение:** второй под (rougenn), H200; venv EXP-030.
- **Решение:** парный bootstrap против EXP-053 (лучший рецепт по сидам) и EXP-054 (кандидат) — справочно; отдельно 45·mAP@10 + 10·отказ и скорость на H200.

## Результаты
Завершён 18.09.2026, протокол `val_v2`, фолд 0. Среднее ± std по сидам 0, 1, 2, fp32; ~50 мин на сид.

| Метрика | EXP-054 (кандидат) | EXP-056 |
|---|---|---|
| mAP@10 | 0,8939 | **0,4676 ± 0,0072** |
| R1 / R5 | 0,871 / 0,973 | 0,407 / 0,687 |
| score отказа (F1 / TNR) | 0,912 (0,906 / 0,926) | 0,641 (0,533 / 0,892) |
| полный mAP / mINP (справочно) | 0,896 / 0,878 | 0,486 / 0,436 |
| время на одно ТС, мс / лучший FPS (H200) | 18,44 / 412,5 (fp16) | 15,39 / 544 (fp32) |
| веса, МБ | 1 715 | 584 |

mAP@10 сидов: 0,4650 / 0,4757 / 0,4620. Срезы: ракурс не встречается на других камерах 0,545; камеры 89/90 0,461; маленькие рамки 0,473; обрезанные рамки 0,249; такси 0,529. Bootstrap против EXP-054 не считался: разрыв −0,43.

## Вывод
- **Решение:** rejected — на 0,43 ниже EXP-054 и ниже простых бэкбонов (CLIP ViT-B/16 EXP-010 — 0,77, R50-IBN EXP-017 — 0,655).
- **Почему:** на наших фолдах точность на train 0,999 при 0,47 на фолде 0 — сильное переобучение; рецепт статьи (Adam 3,5e-4 на всю сеть, 120 эпох) слишком агрессивен для предобученных CLIP и IBN на 924 машинах, наши рабочие рецепты учат бэкбон с lr 1e-5 за 30 эпох. Оба бэкбона на наших данных и так заметно слабее SigLIP 2.
- **Что дальше:** архитектуру не продолжаем.
