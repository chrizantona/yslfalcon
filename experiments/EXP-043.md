# EXP-043 · суп трёх сидов EXP-042 (SigLIP 2)

## Идея
- **Родитель:** EXP-042.
- **Изменение (одно):** равномерный суп весов трёх сидов EXP-042; одна модель и один прямой проход, без ансамбля.
- **Гипотеза:** как у EXP-024 и EXP-037, суп даст небольшой прирост к среднему сиду и один файл весов для сдачи.
- **Почему EXP-042, а не EXP-041:**
  - по mAP@10 EXP-042 лучше: +0,017, 95% CI [+0,008; +0,028];
  - по баллам 45·mAP@10 + 10·отказ он выше примерно на 0,7, хотя отказ чуть ниже (0,914 против 0,919).
- **Пакет изменений:** нет.

## Вывод
- **Решение:** accepted — новый лучший кандидат по качеству.
  - Против EXP-042 прирост супа +0,002 больше разброса сидов (0,0015), но интервал bootstrap задевает ноль. Выигрыш супа — прежде всего один файл весов.
  - Против EXP-037 прирост подтверждён bootstrap (+0,043, CI выше нуля), примерно +2,4 балла по 45·mAP@10 + 10·отказ; против DFN-супа EXP-047 — тоже (+0,022).
- **Почему:** SigLIP 2 → претрейн VERI-Wild → ArcFace с imprinting → суп; выросли все трудные срезы, сильнее всего обрезанные и маленькие рамки. fp16 не меняет качество, скорость на H200 как у EXP-037.
- **Что дальше:**
  - замер на RTX A5000;
  - Docker и сдача для SigLIP 2 (timm-башня, веса можно хранить в fp16);
  - одна проверка на фолде 4;
  - переобучение на фолдах 0–3 с порогом отказа с фолда 4;
  - уточнить у организаторов детерминизм fp16.
