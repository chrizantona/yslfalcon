# EXP-073 · Суп шести сидов рецепта EXP-053

## Идея
- **Родитель:** EXP-072 (тег `exp-072`) — ещё три сида рецепта EXP-053; сравнение с EXP-054 (суп трёх сидов EXP-053).
- **Изменение (одно):** равномерное среднее весов шести сидов (EXP-053 сиды 0–2 и EXP-072 сиды 3–5) вместо трёх.
- **Гипотеза:** суп трёх сидов дал +0,0044 к среднему сидов (EXP-054). Все шесть стартуют с одного претрейна EXP-040 и лежат в одном бассейне; больший суп может добавить ещё немного при той же скорости и размере.
- **Пакет изменений:** нет.

## Вывод
- **Решение:** inconclusive — суп из шести сидов не лучше супа из трёх (EXP-054).
- **Почему:** сиды одного рецепта уже близки друг к другу; добавление сидов 3–5 (они чуть слабее, 0,8884) не сдвигает среднее весов в лучшую сторону.
- **Что дальше:** супы делать из трёх сидов; больше сидов не добавлять.
