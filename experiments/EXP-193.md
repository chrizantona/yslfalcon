# EXP-193 · Цветовой джиттер на наших фолдах

## Идея
- **Родитель:** EXP-161 (тег `exp-161`) — рецепт супа EXP-164: 0,892529 ± 0,002290, отказ 0,929138.
- **Изменение (одно):** `color_jitter: {p: 0.5, brightness: 0.2, contrast: 0.2, saturation: 0.2, hue: 0.05}` — стандартный для ReID мягкий фотометрический джиттер. В нашей линии SigLIP он не применялся ни разу: в конфигах он встречается только в воспроизведённых чужих рецептах (EXP-055…EXP-064).
- **Зачем:** по разбору ошибок ночные камеры 82–86 дают 24% потерь mAP@10 при 13% истинных кадров; там белая машина выглядит бежевой, а красная уходит в засвет. Джиттер учит модель меньше зависеть от освещения. Инференс не меняется.
- **Риск:** цвет — сильный различающий признак (двойники отличаются ливреями каршеринга), сдвиг оттенка может стоить больше, чем даст ночью.
- **Пакет изменений:** нет.

## Запуск
- **Тег:** `exp-193` · **Конфиг:** `configs/exp193_color_jitter.yaml` · дифф: `git diff exp-161 exp-193`
- **Команда:** из `/workspace/yslfalcon_runs/EXP-193/`: `CONFIG=configs/exp193_color_jitter.yaml GPU=1 PARALLEL_SEEDS=0 PREPARED_ENV=/workspace/yslfalcon_runs/EXP-030/.venv bash scripts/pod_train_job.sh` (первый в цепочке GPU 1: EXP-193 → EXP-195 → EXP-196).
- **Протокол:** `configs/val_v2.yaml`, фолд 0; обучение на фолдах 1–3; фолд 4 не трогается. Сиды 0, 1, 2. GPU 3 оставлена свободной.
- **Решение:** против EXP-161 — прирост больше разброса сидов или bootstrap с CI выше нуля; отдельно смотрим срез ночных камер 82–86.
