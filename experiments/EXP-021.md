# EXP-021 · ViT-L/14

## Идея
- **Родитель:** EXP-020.
- **Изменение:** fp16 autocast полного цикла инференса ViT-L; отдельно публичные веса и финальный seed0 с BNNeck.
- **Гипотеза:** ViT-L в fp16 укладывается в бюджет времени и FPS при сохранении качества одного и того же чекпоинта.
- **Пакет изменений:** нет.

## Запуск
- **Тег:** `exp-021`; `git diff exp-020 exp-021`.
- **Внешние веса и данные:** [DATA.md](../DATA.md), закреплённая ревизия LAION/OpenCLIP и sha256; для EXP-022 — публичная версия 1 VERI-Wild test.
- **Потоковость:** да, каждый запрос независимо, TTA и реранкер не добавлены.
- **Конфиг:** `configs/exp021_clip_vitl14_fp16.yaml`.
- **Команда:** `CONFIG=configs/exp021_clip_vitl14_fp16.yaml GPU=3 PREPARED_ENV=/workspace/yslfalcon_runs/EXP-020/.venv setsid nohup bash scripts/pod_benchmark_job.sh > status/job.log 2>&1 < /dev/null &`.
- **Протокол:** `configs/val_v2.yaml`, фолд 0; обучение на фолдах 1–3 по vehicle_id, фолд 4 нетронут. Для EXP-022 обучение только на внешних машинах.
- **Сиды:** не применяется.
- **Окружение:** H200, GPU 1/3/2; Python 3.13.7, Torch 2.10.0+cu130, torchvision 0.25.0; `requirements.txt`, `requirements-pod.txt`; `pytest==9.1.1`. Отдельная venv без системных пакетов.
- **Директория на поде:** `/workspace/yslfalcon_runs/EXP-021/`; названия по просьбе пользователя.

## Условный ночной запуск
`setsid nohup bash scripts/pod_night_job.sh > status/night.log 2>&1 < /dev/null &` из EXP-020. Сначала EXP-020 и EXP-021 параллельно. GPU 3 передаётся обучению только после независимого замера скорости. Для цепочки EXP-022 → EXP-023 → EXP-024 требуется прирост среднего mAP@10 EXP-020 над 0,710 больше max(0,004, std новых сидов). Условие и справочный результат EXP-016 (0,773) записаны в `configs/exp020_clip_vitl14_bot_30ep.yaml`; решение сохраняется в `status/gate.json`.

## Результаты
Предварительный публичный visual tower без BNNeck, H200, 17.09.2026: полный цикл 18,15 мс, forward 7,88 мс; FPS для batch 1/8/16/32 — 47,1 / 285,0 / 370,1 / 422,8. Пиковый VRAM 2 072 МБ; веса FP32 1 215,9 МБ; загрузка 4,4 с; повторные эмбеддинги совпадают побитово. Методика — `reid.benchmark`; 20 баллов применительно к этому H200, перенос на A5000 ещё не проверен. `artifacts/EXP-021/benchmark.json` забран локально с проверкой sha256.

Реальный обученный `exp020_seed0.pt` с BNNeck: полный цикл 18,21 мс, forward 7,85 мс; FPS batch 1/8/16/32 — 46,4 / 301,1 / 378,6 / 421,0. Пиковый VRAM 2 072 МБ, файл FP32 1 218,8 МБ, загрузка 3,04 с, детерминизм 0. Сравнение того же файла в FP32 (EXP-020): 19,59 мс / 190,4 FPS. Обе оценки скорости выполнены после выхода всех процессов обучения.

`reid.precision_eval` оценил тот же заранее выбранный seed0 в fp16 через неизменённый `evaluate_fold`: mAP@10 0,791936 против 0,791848 в FP32, разница +0,000088. R1 0,756376 и R5 0,934916 совпадают. F1 0,835952, TNR 0,921397, score 0,861586 и F1_strict 0,040212 совпали; порог fp16 5,686516. Полный mAP 0,797598, mINP 0,760933 справочно. Это проверка одного и того же seed0; среднее трёх сидов EXP-020 — отдельное сравнение. Неоднозначность junk-кандидата описана в README; H200 не заменяет проверку RTX A5000.
