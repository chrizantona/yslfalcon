# EXP-002 · ResNet50 вместо CLIP ViT-B/16

## Идея
- **Родитель:** EXP-001 (тег `exp-001`)
- **Изменение:** бэкбон ResNet50 (ImageNet, `timm resnet50.a1_in1k`, last stride 1) вместо CLIP ViT-B/16
- **Гипотеза:** CNN быстрее на инференсе, а производительность — 20% оценки. По нулевым результатам нельзя судить, какой бэкбон лучше после дообучения; сравнение покажет, чего стоит выбор по mAP.
- **Пакет изменений:** да, бэкбон вместе с learning rate: 3,5e-4 — значение из Bag of Tricks для ResNet50, у ViT было 1e-5. Нормализация входа берётся от своего бэкбона. Остальной рецепт и бюджет обучения совпадают с EXP-001.

## Запуск
- **Тег:** `exp-002`. EXP-001 и EXP-002 запущены с одного коммита, поэтому отличие видно в конфигах: `git diff --no-index configs/exp001_clip_vitb16_bot.yaml configs/exp002_resnet50_bot.yaml`
- **Конфиг:** `configs/exp002_resnet50_bot.yaml`
- **Команда:** `CONFIG=configs/exp002_resnet50_bot.yaml GPU=<id> setsid nohup bash scripts/pod_train_job.sh > status/job.log 2>&1 < /dev/null &`
- **Протокол:** `val_v1` — обучение на фолдах 1–3, оценка на фолде 0 после 120 эпох; фолд 4 не используется
- **Сиды:** 0, 1, 2 — параллельно на одном GPU
- **Окружение:** 1× H200 на общем поде, torch 2.10.0+cu130
