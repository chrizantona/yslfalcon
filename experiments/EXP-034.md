# EXP-034 · ArcFace с imprinting от претрейна EXP-033

## Идея
- **Родитель:** EXP-028 (тег `exp-028`), текущий принятый рецепт обучения.
- **Изменение (одно):** бэкбон стартует с претрейна EXP-033 (VERI-Wild test + VeRi-776) вместо EXP-022; ArcFace с imprinting и остальной рецепт EXP-028 без изменений.
- **Гипотеза:** претрейн с большим числом межкамерных ракурсов даёт лучший старт для дообучения и лучшие центры для imprinting. Ожидаем mAP@10 выше 0,8395 ± 0,0016 у EXP-028.
- **Пакет изменений:** нет.

## Запуск
- **Тег:** `exp-034` · дифф с родителем: `git diff exp-028 exp-034`
- **Внешние веса и данные:** как у EXP-033.
- **Потоковость:** да.

- **Протокол:** `configs/val_v2.yaml`, фолд 0; обучение на фолдах 1–3; фолд 4 не трогается.

## Вывод
- **Решение:** inconclusive (было rejected по разбросу сидов). Парный bootstrap против EXP-028 по AP из Release `exp-037`: −0,0079, 95% CI [−0,0187; +0,0017] (`bootstrap_EXP-034_vs_EXP-028.json`); по правилу `reid.research_compare` отклонение требует интервала целиком ниже нуля. Прироста нет, вывод прежний.
- **Почему:** VeRi-776 в претрейне не помог дообучению; вероятная причина — другой домен (старые снимки низкого разрешения), отдельно не проверялось. EXP-028 обучался на поде товарища, EXP-034 — на втором поде; код и версии пакетов одинаковые, воспроизводимость между подами отдельно не проверялась.
- **Что дальше:** претрейн оставить на VERI-Wild test.
