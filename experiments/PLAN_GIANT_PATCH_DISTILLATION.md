# Обобщение patch-based KD на vehicle ReID: Giant → текущий SigLIP 2

Источник идеи — *Patch-based Knowledge Distillation for Lifelong Person Re-Identification* (MM 2022). В статье старая
и новая сети одной архитектуры сохраняют знания между этапами. У нас другая задача: учитель Giant/16@384 и ученик
So400m/14@224 имеют разные размеры признака и сетки патчей, а классы VehicleID и LCT не совпадают. Поэтому logits
VehicleID нельзя считать осмысленной целью для LCT.

## Что переносим из статьи

1. **Локальность:** кроме глобального embedding сравниваем несколько информативных участков машины.
2. **Разнообразие патчей:** K=3 участка не должны схлопнуться в одну решётку радиатора или лобовое стекло.
3. **Отношения вместо координат признака:** Huber-loss сопоставляет попарные расстояния патчей внутри снимка и между
   снимками батча. Это работает при 1536 измерениях учителя и другом размере ученика без постоянного projector на
   инференсе.
4. **Аугментации различаются:** teacher видит слабый вид, student — утверждённый сильный вид; координаты патчей
   переносятся в нормализованных координатах между сетками 24×24 и 16×16.

## Что меняем осознанно

- Первый sampler детерминированный: teacher выбирает K=3 сильных неперекрывающихся областей по вкладу токена в
  глобальный descriptor. Learnable Gumbel sampler и patch-logit head из статьи добавляются только отдельной абляцией,
  если отношения уже дают прирост. Это не смешивает сразу три новых механизма.
- Class-logit KD исключён: teacher-классы VehicleID отсутствуют в LCT. Возможная patch-classification голова обучается
  только на LCT train IDs и существует лишь во время обучения.
- Teacher и все projectors — training-only. Финальный checkpoint ученика содержит тот же encoder+BNNeck и остаётся в
  лимите 2 ГБ.

## Последовательные абляции после EXP-167

| Этап | Единственное изменение | Что доказывает |
|---|---|---|
| A | новый Giant teacher в прежнем global relation loss | контроль силы учителя; сравнение с неудачными EXP-153/154/159 |
| B | только intra-image patch relation, K=3 | перенос локальной структуры без межмашинного давления |
| C | + inter-image patch relation | перенос различий между похожими машинами, главный механизм статьи |
| D | global + patch relation | проверка совместимости двух сигналов, только если B/C положительны |
| E | learnable diverse sampler и затем patch logits | дорогие компоненты статьи, только после подтверждения базового механизма |

Каждый этап обучается тремя сидами на фолдах 1–3, оценивается `evaluate_fold` на фолде 0 и сравнивается парным
bootstrap по машинам. Фолд 4 остаётся нетронутым до финального кандидата. Останавливаем линию, если патчевый этап
ухудшает mAP@10 сильнее разброса сидов или улучшает только train loss без AP на малых/обрезанных рамках и ракурсах.
