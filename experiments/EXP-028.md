# EXP-028 · ArcFace с imprinting центров

## Идея
- **Родитель:** EXP-027 (тег `exp-027`).
- **Изменение:** До обучения заполнить веса ArcFace нормированными средними эмбеддингами классов только train-фолдов 1–3; BN-статистики не обновлять.
- **Гипотеза:** Начальные центры могут облегчить дообучение угловой головы.
- **Пакет изменений:** нет.

## Запуск
- **Тег:** `exp-028`; `git diff exp-027 exp-028`. Общий коммит добавляет поддержку нескольких вариантов; семантический дифф конфигов до запуска проверяется `scripts/pod_followup_preflight.py`.
- **Конфиг:** `configs/exp028_vitl14_arcface_imprinting.yaml`; гиперпараметры закреплены в нём.
- **Команда:** `CONFIG=configs/exp028_vitl14_arcface_imprinting.yaml GPU=1 SEED_GPUS=1,3,2 PREPARED_ENV=/workspace/yslfalcon_runs/EXP-026/.venv setsid nohup bash scripts/pod_train_job.sh > status/job.log 2>&1 < /dev/null &`.
- **Общий контроллер:** `setsid nohup bash scripts/pod_followup_job.sh > status/followup_job.log 2>&1 < /dev/null &` из EXP-026; последовательно EXP-025…029 и условно EXP-036, три сида одного обучения параллельно.
- **Внешние данные и веса:** [DATA.md](../DATA.md), LAION/OpenCLIP и VERI-Wild. Без новых загрузок; стартовый visual tower `exp022_seed0.pt`, для EXP-025 — готовый `exp024.pt` с проверкой SHA256.
- **Потоковость:** да, каждый запрос независимо; для EXP-025 TTA только одного снимка.
- **Протокол:** неизменённый `configs/val_v2.yaml`, `evaluate_fold`, dev-фолд 0; train по vehicle_id на фолдах 1–3. Фолд 4 не используется.
- **Сиды:** 0, 1, 2.
- **Окружение:** Python 3.13.7, Torch 2.10.0+cu130, torchvision 0.25.0, OpenCLIP 3.3.0; точные версии в requirements*.txt; pytest 9.1.1. H200, GPU 1/3/2 по UUID; GPU 0 занят сторонним сервисом.
- **Проверка:** 42 теста прошли; 924 машины / 5725 train-кадров; реальный batch 128 при 280 — 46280 MiB, градиенты конечные; ArcFace проверен на реальном ViT-L. SHA256 претрейна и супа совпали, 20 исходных вырезок побайтно совпали с повторным `save_crop`.

## Результаты
Статус: running. Значения будут внесены после завершения; вымышленных метрик нет.

Все retrieval/отказные метрики, порог, полный mAP/mINP сохраняет `evaluate_fold`; AP каждого запроса и эмбеддинги сохраняются. `reid.slices` считает ракурс, 89/90, мелкие/обрезанные рамки, такси; атрибута ночи нет. `reid.benchmark` измеряет полный цикл, FPS 1/8/16/32, VRAM, загрузку, детерминизм и размер.

## Вывод
Решение по качеству — по шуму трёх сидов или парному bootstrap по машинам (2000 повторов, seed 0). Для EXP-028 дополнительно сравнение с EXP-023. Принятые изменения затем проверяются последовательно относительно последнего принятого родителя; самостоятельные ветки не объявляются складывающимися без проверки.

RTX A5000 недоступна: по прямому указанию пользователя её замер отложен. Результаты качества и замер H200 не означают подтверждения лимитов на A5000. Финальная проверка на фолде 4 и переобучение 0–3 выполняются после выбора кандидата, без повторного подбора на фолде 4. Организаторский `evaluate.py` пока не получен; EXP-035 зависит от него.
