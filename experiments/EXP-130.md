# EXP-130 · Опубликованный ConvNeXt-L + GLPE baseline

## Идея
- **Родитель:** EXP-125 (`exp-125`) — ближайшая стабильная реконструкция OT-GFAM + GLPE, mAP@10 `0,460120`.
- **Изменение:** архитектурный пакет из доступного [авторского inference-кода](https://github.com/hidayetergn/v-reid/tree/cb3ac1819e332383f75d9d110c16576b93ccc240): полный ConvNeXt-L, stride последнего stage = 1, 1536 каналов, один общий GeM, шесть отдельных BNNeck, L2 каждой ветви и concat `6×1536`. Непубликованный OT-GFAM временно исключён.
- **Гипотеза:** прежний результат измерял урезанный до 768 каналов backbone и собственную реконструкцию attention. Публично проверяемая GLPE-база должна показать, сколько качества терялось до OT-GFAM.
- **Пакет изменений:** да. Stage 4, размерность, BNNeck и отсутствие OT-GFAM образуют одну опубликованную авторами inference-архитектуру; разделить их без создания ещё одной неавторской схемы нельзя.

## Запуск
- **Тег:** `exp-130`; дифф с родителем: `git diff exp-125 exp-130`.
- **Конфиг:** `configs/exp130_released_convnext_glpe.yaml`.
- **Данные:** LCT folds 1–3; dev fold 0; holdout fold 4 не используется.
- **Веса:** ConvNeXt-L ImageNet-22K из [DATA.md](../DATA.md), sha256 проверяется до загрузки.
- **Обучение:** рецепт EXP-125 сохранён — seed 0, PK 8×4, 60 эпох cosine, Adam, backbone lr `1e-5`, новые GeM/BNNeck/головы `3,5e-4`. Batch-hard оставлен для чистого контроля геометрии; batch-all из статьи проверяется следующим отдельным EXP.
- **Команда:** `CONFIG=configs/exp130_released_convnext_glpe.yaml GPU=3 setsid nohup bash scripts/pod_train_job.sh > status/job.log 2>&1 < /dev/null &`.
- **Чекпоинт:** `855fae489d4843cdb9c49a3943d78c0d.pt`; остаётся на поде.

## Результаты

| Метрика | Значение |
|---|---:|
| mAP@10 | 0,418961 |
| R1 / R5 | 0,378188 / 0,620932 |
| score отказа | 0,654422 |
| F1 / TNR | 0,519417 / 0,969432 |
| полный mAP / mINP | 0,438616 / 0,383596 |

Train accuracy достигла `1,0` уже к 20-й эпохе. Dev mAP@10 рос с `0,304090` на эпохе 10 до `0,418961` на эпохе 60, но остался ниже урезанного EXP-125 (`0,460120`) и EXP-048 (`0,832100`). Финальная оценка завершилась; при последующем сохранении checkpoint сработала квота пода, повреждённый частичный файл удалён. Для отклонённого эксперимента переобучение ради веса не требуется.

## Вывод
- **Решение:** rejected — −0,413139 против EXP-048 и −0,041159 против EXP-125. Это контроль доступного авторского GLPE, а не полное воспроизведение OT-GFAM.
