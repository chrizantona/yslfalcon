# EXP-134 · минимальный вес GLPE-блока

## Идея

- **Родитель:** EXP-133.
- **Одно изменение:** `local_scale: 0.125` вместо `0.25`; checkpoint и все признаки те же.
- **Гипотеза:** слабый локальный сигнал может помочь только как небольшая поправка. При масштабе `0,125` глобальная ветка даёт 98,46% cosine, весь локальный блок — 1,54%.
- **Порог:** результат должен превысить seed 0 EXP-048 (`0,831990`).

## Запуск

- **Тег:** `exp-134`.
- **Конфиг:** `configs/exp134_clip_convnext_glpe_scale0125.yaml`.
- **Checkpoint:** EXP-132 `4380f105f2324d8c8abf7f53303e984f.pt`, sha256 `1dd9d8ba572bcd540d2cd25f8481438d20762d96b41ff7aa3e6ec419a39eae2b`.
- **Команда:** `CONFIG=configs/exp134_clip_convnext_glpe_scale0125.yaml GPU=3 PREPARED_ENV=/tmp/yslfalcon_exp123_preflight/.venv bash scripts/pod_checkpoint_job.sh`.
- **Протокол:** `val_v2`, dev-фолд 0; только повторная оценка, фолд 4 не используется.

## Результаты

| Метрика | Значение |
|---|---:|
| mAP@10 | 0,831138 |
| R1 / R5 | 0,795075 / 0,961302 |

| F1 / TNR / порог | 0,859463 / 0,978166 / 6,204371 |
| полный mAP / mINP | 0,835717 / 0,804914 |

**Решение:** rejected — `−0,000852` против seed 0 EXP-048. Диагностическая матрица по сохранённым компонентам также не нашла прироста: лучший из проверенных вариантов, нижняя треть с `local_scale=0,0625`, дал `0,831676`.
