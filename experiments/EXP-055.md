# EXP-055 · CLIP-SENet: претрейн на VehicleID (reference)

## Идея
- **Родитель:** нет — новая архитектура по просьбе товарища (CLIP-SENet: ResNeXt101-IBN-a + TinyCLIP ViT-B/32, AFEM). Первая стадия цепочки EXP-055 → EXP-056.
- **Изменение:** обучение по рецепту статьи на VehicleID вместо наших фолдов; фолд 0 оценивается без наших данных, как EXP-040 для SigLIP 2.
- **Гипотеза:** в статье архитектура сильна на VeRi-776 / VehicleID / VeRi-Wild. Наши данные против: ResNet50-IBN (EXP-017) — 0,655, CLIP ViT-B/16 (EXP-010) — 0,77, ConvNeXt-L CLIP (EXP-048) — 0,832 при 0,894 у EXP-054; VehicleID в претрейне ViT-B/16 не помог (EXP-039). Ожидаем, что после дообучения (EXP-056) модель будет заметно ниже EXP-054; проверка нужна для полноты сравнения.
- **Пакет изменений:** да — архитектура, лоссы и оптимизатор статьи вместе; по отдельности они не воспроизводят метод.

## Архитектура и рецепт (`src/reid/paper_models.py`, `src/reid/train_paper.py`)
- **Вход** 320×320, ImageNet-нормализация; ветка TinyCLIP перенормирует вход на mean/std CLIP.
- **T^a:** ResNeXt101-IBN-a (32×4d, IBN в layer1–3, ImageNet), GAP → 2048.
- **T^s:** визуальная часть TinyCLIP ViT-61M/32 (LAION-400M; ширина 640, 12 слоёв, 10 голов) с проекцией → 512. Веса HF переложены в timm ViT, позиции интерполированы 7×7 → 10×10; на 224 px выход совпадает с эталонной реализацией transformers (см. «Проверка до запуска»). Текстовая часть не используется.
- **T^u** = FC([T^s, T^a]) → 2048.
- **AFEM:** Linear(512 → 33·2048) → BN → ReLU → 33 вектора; 32 групповых с обучаемыми весами w_i (N(0,1)) гейтят оставленный: T^s' = f + f ⊙ Σ w_i ⊙ g_i. Формула статьи в буквальном виде (Σ w_i ⊗ f(T^s)) сводится к постоянному поканальному масштабу, поэтому взято прочтение из текста.
- **T** = T^u + T^s' (2048) — эмбеддинг поиска; классификатор FC(2048 → классы).
- **Лосс:** CE со сглаживанием 0,1 + SupCon (τ = 0,07 — в описании не задан, как в EXP-053) на T.
- **Оптимизация:** Adam, lr 3,5e-4, L2 5e-4; линейный разогрев, ×0,1 на вехах. PK 16×8 = 128. Аугментации: flip, pad 10 + random crop, random erasing, color jitter (p 0,5; яркость, контраст, насыщенность 0,2, тон 0,05). bf16.
- **CV-метки** (камера и ракурс) не используются: в тесте их нет. Re-ranking — нет, протокол потоковый.

## Запуск
- **Тег:** `exp-055`.
- **Внешние веса и данные:** ResNeXt101-IBN-a, TinyCLIP ViT-61M/32 — URL, лицензии и sha256 в [DATA.md](../DATA.md), `bash scripts/fetch_external.sh paper`; VehicleID — как у EXP-038.
- **Данные:** VehicleID целиком — 221 567 снимков 26 267 машин (официальные списки сплита не распакованы). Эпоха — каждая машина один раз, 8 снимков: 210 тыс. изображений; 60 эпох ≈ 12,6 млн изображений ≈ 120 эпох статьи на train-сплите (110 тыс. снимков). Разогрев 5 эпох, вехи 20 и 35 — 10/40/70 из 120 в том же масштабе.
- **Потоковость:** да.
- **Конфиг:** `configs/exp055_clip_senet_vehicleid.yaml`; чекпоинт `136a8ea131cb4019a68605cbae11ae5f.pt` задан заранее — с него стартует EXP-056.
- **Команда:** очередь `scripts/queues/pod_a_clip_senet.txt` через `scripts/pod_queue_job.sh`; GPU 2.
- **Протокол:** `configs/val_v2.yaml`, фолд 0 — только оценка; фолд 4 не трогается.
- **Сиды:** 0 (reference).
- **Окружение:** второй под (rougenn), H200; venv EXP-030.
- **Решение:** reference, без сравнения; итог цепочки — EXP-056.
- **Проверка до запуска** (второй под, H200, 18.09.2026): веса ResNeXt101-IBN-a (без `fc`) и TinyCLIP загружаются строго; timm-башня TinyCLIP на 224 px совпадает с `CLIPVisionModelWithProjection` из transformers 5.17.0 бит в бит (максимальная разница 0,0; transformers ставился во временную папку только для этой сверки). 197,5 млн параметров при 26 267 классах. Шаг обучения на батче 128 (bf16) — 0,228 с, 561 изображение/с, пик памяти 29,6 ГБ; претрейн ≈ 6,2 ч.
