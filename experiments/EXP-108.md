# EXP-108 · три сида принятого CLIP-SENet

## Идея
- **Родитель:** EXP-106 (тег `exp-106`) — принятый TinyCLIP-61M/32 + компактный AFEM, 124 эпохи.
- **Изменение:** три независимых сида 0/1/2 вместо диагностического seed 0; архитектура и рецепт неизменны.
- **Гипотеза:** измерить шум рецепта и получить три checkpoint из одного бассейна для uniform weight soup.
- **Пакет изменений:** нет; это обязательная репликация, а не новая модельная гипотеза.

## Запуск
- **Тег:** `exp-108` · дифф с родителем: `git diff exp-106 exp-108`
- **Внешние веса и данные:** как у EXP-106; новых источников нет.
- **Потоковость:** да.
- **Конфиг:** `configs/exp108_clip_senet_three_seeds.yaml`.
- **Команда:** `GPU=2 SEED_GPUS=2,3 PARALLEL_SEEDS=1 MAX_PARALLEL_SEEDS=2`; два сида параллельно, третий после них, без остановки чужих процессов.
- **Протокол:** `val_v2`; train folds 1–3, dev fold 0; holdout fold 4 не используется.
- **Сиды:** 0, 1, 2.

## Вывод
- **Решение:** inconclusive относительно одиночного EXP-106; основная цель — измерение шума — выполнена.
- **Почему:** seed 0 был удачнее среднего, но доверительный интервал разницы пересекает ноль; измеренный std mAP@10 равен 0,005721.
- **Что дальше:** EXP-109 складывает ровно эти три checkpoint в uniform weight soup.
