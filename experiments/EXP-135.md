# EXP-135 · EXP-048 + signed GLPE

## Идея

- **Родитель:** EXP-132.
- **Одно изменение:** общий локальный pooling меняется с авторского `clamp(x, eps)` GeM на знаковый power mean `GeM(x⁺) − GeM(x⁻)`. Архитектура полос, обучение, fusion и замороженный EXP-048 не меняются.
- **Гипотеза:** последняя карта OpenCLIP ConvNeXt знаковая, поэтому положительный clamp выбрасывает часть семантического сигнала. Знаковый вариант сохраняет обе половины распределения; в исторической OT-GFAM-ветке такой переход дал EXP-124 `+0,0481` к EXP-123.
- **Критерий:** сначала локальный блок должен стать заметно сильнее `0,519238` EXP-132; итоговый fusion должен превысить seed 0 EXP-048 `0,831990`. Иначе GLPE поверх этой базы закрывается.

## Запуск

- **Тег:** `exp-135`.
- **Конфиг:** `configs/exp135_clip_convnext_glpe_signed.yaml`.
- **Команда:** `CONFIG=configs/exp135_clip_convnext_glpe_signed.yaml GPU=3 PARALLEL_SEEDS=0 PREPARED_ENV=/tmp/yslfalcon_exp123_preflight/.venv setsid nohup bash scripts/pod_train_job.sh > status/job.log 2>&1 < /dev/null &`.
- **Протокол:** `val_v2`, train-фолды 1–3, dev-фолд 0; фолд 4 не используется.
- **Родительский checkpoint:** EXP-048 seed 0, sha256 `0d8696dec7fb8027a75540453a8def119ad9c0ab3e46a6bcaf6614a003f48a6e`.
- **Потоковость:** да.

## Результаты

| Метрика | Значение |
|---|---:|
| mAP@10 | 0,823494 |
| R1 / R5 | 0,785400 / 0,952507 |
| score отказа | 0,892998 |
| F1 / TNR / порог | 0,862112 / 0,965066 / 6,069614 |
| полный mAP / mINP | 0,828176 / 0,796299 |
| H200 latency / FPS | 19,17 мс / 234,2 |
| размер checkpoint | 827,8 МБ |

Signed pooling улучшил локальный блок с `0,519238` в EXP-132 до `0,625998`, а fusion с весом 20% — с `0,815435` до `0,823494`. Но это всё ещё `−0,008496` против глобального EXP-048 seed 0 (`0,831990`). Ни одна проверенная комбинация полос и масштабов не превысила родителя; лучший вариант — только нижняя треть с `local_scale=0,03125` — дал `0,831936`, то есть практически выключил локальную ветку и остался на `−0,000054` ниже.

**Решение:** rejected. GLPE не даёт дополняющего сигнала к EXP-048; OT-GFAM на этот гибрид не переносится, пока нет более сильной локальной ветки или опубликованного авторского кода.
