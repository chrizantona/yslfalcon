# EXP-109 · суп трёх сидов CLIP-SENet

## Идея
- **Родитель:** EXP-108 (тег `exp-108`) — три независимых сида принятого рецепта EXP-106.
- **Изменение (одно):** равномерно усреднить веса трёх сидов; на инференсе остаются одна модель и один forward.
- **Гипотеза:** weight soup уменьшит шум дообучения и даст качество выше среднего трёх сидов без роста времени и размера инференса.
- **Пакет изменений:** нет.

## Запуск
- **Тег:** `exp-109` · дифф с родителем: `git diff exp-108 exp-109`.
- **Внешние веса и данные:** как у EXP-108; новых источников нет.
- **Потоковость:** да; каждый запрос кодируется независимо, другие запросы не используются.
- **Конфиг:** `configs/exp109_clip_senet_soup.yaml`.
- **Команда:** `SOUPS=configs/exp109_clip_senet_soup.yaml GPU=2 setsid nohup bash scripts/pod_eval_job.sh ...`; запуск только после успешного завершения всех сидов EXP-108.
- **Протокол:** `val_v2`; dev fold 0; holdout fold 4 не используется.
- **Состав:** `exp108_seed0.pt`, `exp108_seed1.pt`, `exp108_seed2.pt`; результат `exp109.pt`.
- **Окружение:** H200, свободная GPU 2 или 3; чужие процессы не меняются.

## Вывод
- **Решение:** accepted внутри ветки CLIP-SENet.
- **Почему:** прирост одновременно больше шума по сидам, статистически значим против среднего EXP-108 и против удачного seed 0, а score отказа также вырос.
- **Практический предел:** 0,6911 всё ещё существенно ниже основного кандидата EXP-054/090 (~0,894–0,898), поэтому CLIP-SENet не становится финальным кандидатом всей задачи.
