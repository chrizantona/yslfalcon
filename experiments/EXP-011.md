# EXP-011 · FastReID ResNet50-IBN, VERI-Wild — без дообучения

Статус `reference`: публичный чекпоинт, оценённый на фолде 0 как есть. В сравнениях с кандидатами не участвует; нужен, чтобы понять, стоит ли брать эти веса учителем или стартом.

## Идея
- **Родитель:** нет
- **Что оцениваем:** FastReID BoT ResNet50-IBN, обученный на train VERI-Wild (30 671 машина, 277 797 снимков): `fast-reid/veriwild_bot_R50-ibn.pth`, Apache-2.0, https://github.com/JDAI-CV/fast-reid
- **Гипотеза:** самый большой набор машин из доступных нам; тот же тип камер, что у VERI-Wild test в EXP-009 (0,544). Ожидаем близко к EXP-009 или выше: машин в 3 раза больше, но CNN с ImageNet, а не CLIP. Для сравнения: CLIP без обучения (EXP-000) — 0,312, претрейн на VERI-Wild test (EXP-009) — 0,544, бейзлайн EXP-010 — 0,774.
- **Как устроен признак:** как в оригинальном репозитории при тесте — см. `src/reid/teachers.py`; вход 256×256, вырезка по рамке без сохранения пропорций, как у наших моделей

## Запуск
- **Тег:** `exp-011`. EXP-011…EXP-016 запущены с одного коммита
- **Конфиг:** `configs/exp011_ref_fastreid_r50ibn_veriwild.yaml`
- **Команда:** `EVALS="configs/exp011_ref_fastreid_r50ibn_veriwild.yaml configs/exp012_ref_fastreid_r50ibn_vehicleid.yaml configs/exp013_ref_clipreid_vitb16_vehicleid.yaml configs/exp014_ref_clipreid_vitb16_veri.yaml" ENSEMBLES=configs/exp015_ensemble_exp010_seeds.yaml SOUPS=configs/exp016_soup_exp010_seeds.yaml GPU=<id> setsid nohup bash scripts/pod_eval_job.sh > status/job.log 2>&1 < /dev/null &`
- **Протокол:** `val_v1`, фолд 0; порог отказа по z-score, лучший F1 при TNR ≥ 0,5
- **Сиды:** не нужны (без обучения)
- **Окружение:** 1× H200 на общем поде, torch 2.10.0+cu130
- **Лицензии и данные:** веса открытые, но обучены на датасетах с некоммерческими условиями; перечислить в Readme. Скрыты ли номера в VehicleID, неизвестно.
