# EXP-015 · Ансамбль трёх сидов EXP-010

## Идея
- **Родитель:** EXP-010 (тег `exp-010`)
- **Изменение (одно):** вместо эмбеддинга одной модели — среднее L2-нормированных эмбеддингов трёх сидов EXP-010, нормированное заново. Считается по сохранённым эмбеддингам фолда 0, без переобучения.
- **Гипотеза:** сиды ошибаются по-разному, и среднее даёт прирост mAP. Разброс по сидам у EXP-010 — 0,005, ожидаем +0,005…0,015. Это потолок для супа весов EXP-016, который стоит одного прогона модели.
- **Пакет изменений:** нет
- **Цена:** три прогона модели на снимок: forward ×3, веса ×3 (~1 ГБ, в лимит 2 ГБ укладывается)

## Запуск
- **Тег:** `exp-015`. EXP-011…EXP-016 запущены с одного коммита
- **Конфиг:** `configs/exp015_ensemble_exp010_seeds.yaml`
- **Команда:** `EVALS="configs/exp011_ref_fastreid_r50ibn_veriwild.yaml configs/exp012_ref_fastreid_r50ibn_vehicleid.yaml configs/exp013_ref_clipreid_vitb16_vehicleid.yaml configs/exp014_ref_clipreid_vitb16_veri.yaml" ENSEMBLES=configs/exp015_ensemble_exp010_seeds.yaml SOUPS=configs/exp016_soup_exp010_seeds.yaml GPU=<id> setsid nohup bash scripts/pod_eval_job.sh > status/job.log 2>&1 < /dev/null &`; в папку прогона копируются `artifacts/EXP-010/seed{0,1,2}/{query,gallery}_emb.npy`
- **Протокол:** `val_v1`, фолд 0; сравнение с EXP-010 bootstrap-ом по машинам
- **Сиды:** один результат из трёх сидов EXP-010

### Дополнительный замер: склейка с учителем EXP-011
Эмбеддинги EXP-015 и EXP-011 нормированы и склеены с весом учителя w (по сходствам: (1 − w)·cos_ViT + w·cos_CNN). Это разведка, а не результат: вес смотрели на фолде 0.

| Вес учителя | 0 | 0,25 | 0,5 |
|---|---|---|---|
| mAP | 0,781 | 0,786 | 0,758 |
| F1 при пороге | 0,716 | 0,714 | 0,667 |

Учитель без дообучения слабее EXP-010 на 0,21 mAP, поэтому даже с малым весом добавляет лишь +0,005, а с равным — ухудшает. Разнообразие CNN + ViT имеет смысл проверять после дообучения ResNet50-IBN на наших данных, а вес подбирать out-of-fold.

## Вывод
- **Решение:** accepted, но в сдачу не идёт
- **Почему:** прирост +0,006, интервал выше нуля; но скорость и размер весов втрое хуже. Суп весов EXP-016 даёт статистически неотличимый результат (−0,002, CI [−0,005; +0,001]) за цену одной модели.
- **Что дальше:** суп вместо ансамбля сидов; ансамбль разных архитектур — после дообучения ResNet50-IBN с весов VERI-Wild.
