# EXP-084 · EXP-054 + обучаемая ветка четырёх локальных областей

## Идея
- **Родитель:** EXP-054 (тег `exp-054`), 0,8939. Контрольная точка сохраняется целиком: при α = 0 ранжирование в точности как у EXP-054.
- **Изменение (одно):** рядом с замороженной глобальной ветвью EXP-054 (ствол SigLIP 2, его MAP-пулинг и BNNeck со статистиками) — локальная ветвь по патч-токенам (16×16 до MAP): 4 обучаемые мягкие маски (линейный слой токен → 4 логита, softmax по токенам) → 4 взвешенных пулинга → общая проекция 1152 → 256 → BNNeck → L2 каждой области → concat → L2 = l. Эмбеддинг — concat(√(1−α)·g, √α·l). Учится только ветвь (1,25 млн параметров): ArcFace (s 30, m 0,5) с imprinting + SupCon (τ 0,07), lr 5e-4, 30 эпох, разогрев 10, PK 32×4, аугментации EXP-053.
- **Гипотеза:** g хорошо описывает машину целиком; ветвь может выделить детали (фары, решётка, колёса), которые MAP-пулинг сгладил. Оговорка: MAP сам — внимательный пулинг по тем же токенам (16 голов), дообученный в EXP-054, поэтому ожидание скромное (0…+0,005). Отличие от AFEM (EXP-066/069): ветвь работает с пространственными токенами до пулинга, а не с готовым вектором; подход близок к обучаемым мягким областям в Vehicle ReID (MUSP). Идея — от пользователя.
- **Пакет изменений:** нет.

- **Протокол:** `configs/val_v2.yaml`, фолд 0; обучение ветви на фолдах 1–3; фолд 4 не трогается. α = 0; 0,05; 0,1; 0,2 заданы заранее, по каждому — свой каталог `artifacts/EXP-084/alpha_<α>/`; для сводки пода зафиксировано α = 0,1.
- **Сиды:** 0, 1, 2.

- **Проверка до запуска:** одна эпоха на сид 0 — α = 0 даёт 0,893897 и отказ 0,911910 (EXP-054 бит в бит); 722 изображения/с, эпоха ~13 с; голова 5 МБ.

Выбор лучшего α на фолде 0 завышает оценку — принимаем только при CI выше нуля и подтверждаем на фолде 4. Если принят — отдельным EXP разморозка двух последних блоков SigLIP 2 с lr 1e-6 и проверка скорости на A5000.

## Вывод
- **Решение:** inconclusive — прироста нет ни при одном заранее заданном α. Лучшая точка +0,0002 (α = 0,1), её CI [−0,0015; +0,0021]. Разброс сидов (до 0,0009 при α = 0,2) того же порядка, что и сам прирост.
- **Почему:** ветка учится: точность на train 0,87 при 924 классах. Но на новых машинах фолда 0 она не добавляет к g ничего своего. Вместе с EXP-083 это значит: в патч-токенах замороженного EXP-054 нет различающей информации, которую его MAP-пулинг (16 голов внимания, дообученных в EXP-054) бы не забрал.
- **Что дальше:** разморозку двух последних блоков SigLIP 2 не ставим — план предусматривал её только при положительном результате. Локальные ветки по этим токенам закрываем; следующее — сочетание принятых изменений рецепта (τ 0,1 + SupCon с triplet).
