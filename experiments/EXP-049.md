# EXP-049 · SigLIP 2: отступ ArcFace 0,3

## Идея
- **Родитель:** EXP-042 (тег `exp-042`) — принятый рецепт SigLIP 2: претрейн VERI-Wild, ArcFace с imprinting.
- **Изменение (одно):** Отступ ArcFace 0,3 вместо 0,5. Остальное как в EXP-042.
- **Гипотеза:** Отступ 0,5 взят из статьи ArcFace для лиц, где классов десятки тысяч. У нас 924 машины и 840 шагов обучения, поэтому меньший отступ может сойтись лучше. На ViT-L/14 отступ не подбирался.
- **Пакет изменений:** нет.

## Запуск
- **Тег:** `exp-049` · дифф с родителем: `git diff exp-042 exp-049`
- **Внешние веса и данные:** как у EXP-042 (SigLIP 2 So400m/14, претрейн `b155ab652c084d75bf3054d188e01313.pt`); новых загрузок нет.
- **Потоковость:** да.
- **Конфиг:** `configs/exp049_siglip2_arcface_m03.yaml`
- **Команда:** очередь `scripts/queues/pod_a_night_a.txt` через `scripts/pod_queue_job.sh`; сиды по одному на GPU 1 (одно обучение SigLIP 2 — около 42 ГБ).
- **Протокол:** `configs/val_v2.yaml`, фолд 0; обучение на фолдах 1–3; фолд 4 не трогается.
- **Сиды:** 0, 1, 2.
- **Окружение:** второй под (rougenn), H200; Python 3.13.7, torch 2.10.0+cu130, open_clip 3.3.0, timm 1.0.29.
- **Решение:** против EXP-042 (0,8834 ± 0,0015) — прирост больше разброса сидов или парный bootstrap по машинам с CI выше нуля (AP EXP-042 есть локально). Отдельно смотрим 45·mAP@10 + 10·отказ: у ArcFace отказ проседает, и изменения головы могут это сдвинуть.

## Вывод
- **Решение:** inconclusive — интервал содержит ноль, среднее ниже.
- **Почему:** меньший отступ не улучшил поиск, а разброс сидов вырос втрое (0,0046 против 0,0015); срезы ниже. Отказ немного лучше (TNR 0,962), но по сумме баллов EXP-042 впереди.
- **Что дальше:** отступ 0,5 оставить.
