# EXP-039 · ViT-B/16 со стартом от претрейна EXP-038

## Идея
- **Родитель:** EXP-010 (тег `exp-010`).
- **Изменение (одно):** бэкбон стартует с претрейна EXP-038 (VERI-Wild test + VehicleID) вместо EXP-009; остальной рецепт EXP-010 без изменений.
- **Гипотеза:** если VehicleID полезен как данные для претрейна, mAP@10 будет выше 0,767 ± 0,005 у EXP-010.
- **Пакет изменений:** нет.

## Запуск
- **Тег:** `exp-039` · дифф с родителем: `git diff exp-010 exp-039`
- **Внешние данные:** как у EXP-038.
- **Потоковость:** да.
- **Конфиг:** `configs/exp039_vitb16_init_exp038.yaml`
- **Команда:** очередь `scripts/queues/pod_a_vehicleid.txt` после EXP-038, сиды по одному на GPU 0. Код — коммит исправления чтения `train.csv` (см. EXP-038); сам EXP-039 это чтение не использует.
- **Протокол:** `configs/val_v2.yaml`, фолд 0; обучение на фолдах 1–3; фолд 4 не трогается.
- **Сиды:** 0, 1, 2.
- **Окружение:** второй под (rougenn), H200 GPU 0.
- **Решение:** парный bootstrap по машинам против EXP-010 (его AP лежат локально). Переносить VehicleID в претрейн SigLIP 2 стоит, только если CI выше нуля, а лучше при приросте от +0,01. На ViT-L эффект данных для претрейна был меньше, чем на ViT-B (+0,039 против +0,057).

## Вывод
- **Решение:** inconclusive: −0,004, интервал содержит ноль; срезы не выросли.
- **Почему:** VehicleID в претрейне не помогает ViT-B/16 — порог для переноса на SigLIP 2 (CI выше нуля, лучше от +0,01) не выполнен. Вероятные причины — только фронтальные и задние ракурсы и другой домен; отдельно не проверялось.
- **Что дальше:** претрейн SigLIP 2 на VERI-Wild + VehicleID не запускать.
