## Архитектура

SigLIP 2 получает один снимок машины и выдаёт **один глобальный вектор размерности 1152** (проверено на H200). AFEM
не получает patch tokens, карты признаков, камеры или другие запросы. 32 независимых
ветви `Linear(D,512) → LayerNorm → GELU` преобразуют **весь** вектор. Глобальные
обучаемые scalar gates, нормированные softmax, взвешивают их выходы, которые суммируются.
Выход — основная проекция `Linear(D,512)` плюс эта сумма с обучаемым коэффициентом,
начально 0,001. AFEM не содержит классификатора и собственного loss.

OSNet-AIN x1.0 работает независимо на том же crop после той же аугментации, но с
ImageNet-нормализацией. Используются стандартные AIN блоки и авторские ImageNet-веса.
Карта перед исходной FC/classifier → GeM (p=3, нижняя граница 1) → проекция 512.
В объединении каждый вектор отдельно L2-нормируется, затем конкатенируется в 1024.
Общий BNNeck/ArcFace используется для обучения, общий BNNeck-дескриптор — на инференсе.
У CNN есть самостоятельные auxiliary BNNeck/ArcFace и SupCon; вес auxiliary loss = 1.
Эти головы не вызываются на инференсе. Камеры служат только PK sampler и оценке.

## Контрольные сравнения

| EXP | Родитель | Изменение | Назначение |
|---|---|---|---|
| 065 | 054 | Visual tower супа → новая проекция 512 и новые головы, 30 эпох | Контроль дополнительного дообучения и проекции |
| 066 | 065 | AFEM вместо одной проекции | Вклад AFEM отдельно |
| 067 | 054 | OSNet-AIN ImageNet → GeM → проекция 512 | CNN отдельно, тот же рецепт обучения |
| 068 | 065 | Независимая CNN, concat и auxiliary loss | Вклад CNN без AFEM |
| 069 | 068 | AFEM на семантической ветви | Полная архитектура, вклад AFEM при объединении |

Сравниваем 066 с 065, 068 с 065 и 067, 069 с 068 и 066; итоговые кандидаты — с 054.
Для сравнения с 054 нужны его per-query AP. Иначе paired bootstrap с ним невозможен.
Не приписываем AFEM эффект дополнительных эпох: его контролируют 065/068.
BNNeck и классификаторы создаются заново из-за новой размерности, их центры imprinting
считаются по train в eval mode без изменения running statistics.

## Замороженный рецепт

Конфиги `configs/exp065_*.yaml`…`configs/exp069_*.yaml`. Три сида 0/1/2, 30 эпох,
warmup 10, P=32/K=4, ArcFace s=30/m=0,5 с imprinting, SupCon τ=0,07,
lr pretrained towers 1e-5, новых слоёв/голов 5e-4, AdamW wd=1e-4, label smoothing 0,1.
Flip/pad/erasing, input 224, crops 512 — как EXP-053, из которого получен суп EXP-054.
Новых данных для обучения не добавляется. `val_v2`: train 1/2/3, dev 0, holdout 4
остаётся нетронутым. Оценку считает только `evaluate_fold`.
