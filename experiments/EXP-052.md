# EXP-052 · SigLIP 2: lr бэкбона 2e-5

## Идея
- **Родитель:** EXP-042 (тег `exp-042`) — принятый рецепт SigLIP 2: претрейн VERI-Wild, ArcFace с imprinting.
- **Изменение (одно):** lr бэкбона 2e-5 вместо 1e-5. Остальное как в EXP-042.
- **Гипотеза:** Обратная проверка к EXP-051: возможно, наоборот, SigLIP 2 за 30 эпох недоучивается. У ViT-B/16 меньший lr вредил на коротком расписании.
- **Пакет изменений:** нет.

## Запуск
- **Тег:** `exp-052` · дифф с родителем: `git diff exp-042 exp-052`
- **Внешние веса и данные:** как у EXP-042 (SigLIP 2 So400m/14, претрейн `b155ab652c084d75bf3054d188e01313.pt`); новых загрузок нет.
- **Потоковость:** да.
- **Конфиг:** `configs/exp052_siglip2_lr2e-5.yaml`
- **Команда:** очередь `scripts/queues/pod_a_night_c.txt` через `scripts/pod_queue_job.sh`; сиды по одному на GPU 3 (одно обучение SigLIP 2 — около 42 ГБ).
- **Протокол:** `configs/val_v2.yaml`, фолд 0; обучение на фолдах 1–3; фолд 4 не трогается.
- **Сиды:** 0, 1, 2.
- **Окружение:** второй под (rougenn), H200; Python 3.13.7, torch 2.10.0+cu130, open_clip 3.3.0, timm 1.0.29.
- **Решение:** против EXP-042 (0,8834 ± 0,0015) — прирост больше разброса сидов или парный bootstrap по машинам с CI выше нуля (AP EXP-042 есть локально). Отдельно смотрим 45·mAP@10 + 10·отказ: у ArcFace отказ проседает, и изменения головы могут это сдвинуть.

## Вывод
- **Решение:** inconclusive — среднее совпадает, разброс сидов вырос (0,0039 против 0,0015), отказ немного ниже.
- **Почему:** удвоенный шаг не даёт выигрыша; вместе с EXP-051 это значит, что 1e-5 — разумная точка для SigLIP 2 на этом расписании.
- **Что дальше:** lr не трогать; рецепт EXP-042 устойчив к lr, сглаживанию и отступу.
