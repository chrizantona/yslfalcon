# EXP-061 · ConvNeXt-L + BN + OT-GFAM + GLPE по уточнённой схеме: претрейн на VehicleID (reference)

## Идея
- **Родитель:** EXP-059 (тег `exp-059`) — BatchNorm2d на карте stage 3 (без него модель схлопывается, EXP-057).
- **Изменение:** уточнения товарища к схеме статьи — пакет из двух правок:
  - дескриптор поиска — конкатенация шести L2-нормированных эмбеддингов (6 × 768 = 4 608) вместо их среднего;
  - гейт обоих юнитов, W-GFAM и SW-GFAM, считается от входа блока OT-GFAM, а не от выхода W-GFAM.
- **Проверено по списку товарища** (код и тест `test_convnext_glpe_follows_the_described_layout`): один блок OT-GFAM (W-GFAM + SW-GFAM, не стек); ConvNeXt-L, stage 3, карта 14×14; ONN порядка 3; лосс суммируется по шести веткам; все шесть эмбеддингов L2-нормированы; окна 7×7, сдвиг (−3, −3) до внимания и (+3, +3) после; в каждом батче 8 машин по 4 снимка (проверялось на каждом из 1 500 шагов). Лосс по веткам пишется в `train_log.jsonl` (`loss_branches`: global, две полосы, три полосы).
- **Гипотеза:** обе правки приближают реализацию к статье; ожидаем, что итог цепочки (EXP-062) будет ниже EXP-054.
- **Пакет изменений:** да — обе правки описывают одну и ту же схему статьи, по отдельности не проверяются.

## Проверка до запуска
1 500 шагов на 500 машинах VehicleID (PK 8×4, Adam 1e-4), лосс по группам веток (global / две полосы / три полосы):

| Вариант | Лосс в конце (global / two / three) | Точность | Triplet | Косинус между машинами |
|---|---|---|---|---|
| уточнённая схема, ONN 3, без BN | 6,40 / 12,79 / 19,19 (не падает) | 0,001 | 0,300 | 1,000 |
| уточнённая схема, ONN 2, без BN | 6,40 / 12,80 / 19,20 (не падает) | 0,000 | 0,300 | 1,000 |
| **уточнённая схема + BN на stage 3** | 2,37 / 4,58 / 6,64 (с 6,56 / 13,11 / 19,66) | 0,78 | 0,03 | 0,49 |

Без BatchNorm на stage 3 модель схлопывается и с уточнениями, и с ONN порядка 2: причина — два «массивных» канала ConvNeXt-L (см. EXP-057). Поэтому BN сохраняется.

## Результаты
Остановлен 18.09.2026 на 16-й эпохе: **на 15-й эпохе лосс стал NaN во всех шести ветках.** До этого модель училась: сумма 61,9 → 42,8, ветки снижались одинаково (10,31 → 7,10…7,16), точность на train 0 → 0,004; lr вышел на 3,5e-4 на 11-й эпохе. Лог — `artifacts/EXP-061/`.

Причина — обучаемый показатель GeM. Диагностика (`artifacts/EXP-061/diagnosis/`: 2 000 машин VehicleID, PK 8×4, Adam 3,5e-4 без разогрева, 2 000 шагов): p во всех шести ветках монотонно падает — по рецепту 3,00 → 2,97 → 2,93 → 2,87 → 2,80 (каждые 500 шагов), без weight decay на p медленнее, 2,83–2,90; ONN при этом спокойны (|предактивация| ≤ 4). При такой скорости p доходит до нуля за ~40 тыс. шагов, и `pow(1 / p)` даёт NaN — как раз к 15-й эпохе (~49 тыс. шагов с разогревом).

## Вывод
- **Решение:** invalid — обучение сломалось; чекпоинта и оценки на фолде 0 нет; EXP-062 не запускался.
- **Что дальше:** EXP-063 — то же с p ≥ 1 (p = 1 — обычное усреднение); в `reid.train_paper` добавлены остановка при первом NaN и запись p по эпохам (`gem_p`).
