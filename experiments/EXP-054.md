# EXP-054 · Суп трёх сидов EXP-053 (SigLIP 2 с SupCon)

## Идея
- **Родитель:** EXP-053 (тег `exp-053`) — рецепт EXP-042 с SupCon вместо triplet; accepted против EXP-042: +0,0061, 95% CI [+0,0005; +0,0116].
- **Изменение (одно):** равномерное среднее весов трёх сидов EXP-053 вместо одного сида — тот же приём, что EXP-043 для EXP-042.
- **Гипотеза:** сиды стартуют с одного претрейна EXP-040 и лежат в одном бассейне, поэтому суп не хуже среднего сида (у EXP-043 +0,002). Если так, суп заменяет EXP-043 как кандидат на сдачу: один энкодер, та же скорость.
- **Пакет изменений:** нет.

## Запуск
- **Тег:** `exp-054` · дифф с родителем: `git diff exp-053 exp-054`
- **Внешние веса:** SigLIP 2 So400m/14 — только архитектура, веса берутся из чекпоинтов сидов; sha256 в [DATA.md](../DATA.md).
- **Потоковость:** да.
- **Конфиги:** `configs/exp054_soup_exp053_seeds.yaml`; проверка fp16 — `configs/check_exp054_fp16.yaml`.
- **Команда:** `SOUP=configs/exp054_soup_exp053_seeds.yaml CHECK=configs/check_exp054_fp16.yaml GPU=2 PREPARED_ENV=/workspace/yslfalcon_runs/EXP-030/.venv setsid nohup bash scripts/pod_soup_job.sh > status/job.log 2>&1 < /dev/null &`
- **Состав супа:** `f8e64fdd49d24cd993b662553cf3fa57.pt`, `7c4c4b9ac76a4f0bae2a512d726a6853.pt`, `8367afa995e0474cb15d9ddc5926d3e9.pt` (сиды 0, 1, 2); результат — `95aa27ed552c43a1ad9c3d853390fa18.pt`.
- **Протокол:** `configs/val_v2.yaml`, фолд 0; фолд 4 не трогается.
- **Окружение:** второй под (rougenn), H200; venv EXP-030.
- **Решение:**
  - против EXP-043 — парный bootstrap по машинам, интервал выше нуля (разброс сидов у супов не измерен); отдельно 45·mAP@10 + 10·отказ;
  - против EXP-053 — справочно, как EXP-043 против EXP-042;
  - качество fp16 — тем же `evaluate_fold`; скорость fp16 — `reid.benchmark`.

## Вывод
- **Решение:** accepted — против EXP-043 интервал bootstrap выше нуля; EXP-054 — новый лучший кандидат.
- **Почему:** SupCon (EXP-053) и суп складываются: +0,0061 от лосса и +0,0044 от супа. Срезы выросли все, сильнее всего — обрезанные рамки (+0,025) и такси (+0,031). Отказ на уровне EXP-043 (0,912 против 0,914), по сумме баллов +0,35.
- **Что дальше:** EXP-054 вместо EXP-043 в Docker и сабмите (fp16, порог 7,33); одна проверка на фолде 4 против EXP-037; переобучение на фолдах 0–3 по рецепту EXP-053.
