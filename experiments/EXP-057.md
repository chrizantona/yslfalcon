# EXP-057 · ConvNeXt-L + OT-GFAM + GLPE: претрейн на VehicleID (reference)

## Идея
- **Родитель:** нет — новая архитектура по просьбе товарища. Первая стадия цепочки EXP-057 → EXP-058.
- **Изменение:** обучение по рецепту статьи на VehicleID вместо наших фолдов; фолд 0 оценивается без наших данных.
- **Гипотеза:** ConvNeXt-L из ImageNet-22k без CLIP-претрейна; у нас CLIP ConvNeXt-L-D дал 0,832 (EXP-048) против 0,894 у EXP-054. Ожидаем, что после дообучения (EXP-058) модель будет ниже EXP-054; оконное внимание и полосы GLPE могут помочь на обрезанных рамках.
- **Пакет изменений:** да — архитектура, лоссы и оптимизатор статьи вместе.

## Архитектура и рецепт (`src/reid/paper_models.py`, `src/reid/train_paper.py`)
- **Вход** 224×224; ConvNeXt-L (`convnext_large.fb_in22k`) до stage 3 включительно → 768×14×14; stage 4 и голова отброшены.
- **OT-GFAM:** два pre-norm юнита, W-GFAM и SW-GFAM: x + GFAM(LN x) + MLP(LN x) → LN. GFAM — глобальный гейт (GAP входа юнита → Linear → GELU → Linear → sigmoid) умножает токены окон 7×7; Q, K, V — ONN-слои tanh(Σ_{q=1..3} W_q x^q + b); внимание внутри окна, 8 голов (d_k 96), без выходной проекции. SW-юнит сдвигает карту циклически на 3 и маскирует пары токенов из разных областей, как Swin. MLP 768 → 3072 → 768.
- **GLPE:** GeM (обучаемый p, старт 3) по всей карте, по 2 полосам (7+7 строк) и по 3 (5+5+4) → 6 векторов 768 со своими классификаторами; эмбеддинги — их L2-нормы. Эмбеддинг поиска — L2(среднее шести) (в статье противоречие concat / average — взято среднее, Eq. 21).
- **Лосс** на каждом из шести: CE со сглаживанием 0,1 + 0,5 · batch-hard triplet (отступ 0,3) на нормированном эмбеддинге.
- **Оптимизация:** Adam, lr 3,5e-4, L2 5e-4, разогрев 10 эпох; вехи ×0,1 на 40 и 70 (в статье не названы — как у CLIP-SENet). PK 8×4 = 32. Аугментации: flip, random erasing, color jitter (как EXP-055), без pad-crop. bf16.
