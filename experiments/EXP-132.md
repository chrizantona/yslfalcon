# EXP-132 · EXP-048 + frozen GLPE stripes

## Идея

- **Родитель:** EXP-048, seed 0 (`4718026ca2bd46469e224792ba816d49.pt`).
- **Одно изменение:** к неизменной глобальной CLIP-ветке EXP-048 добавляются пять локальных полос GLPE из статьи: две половины и три трети карты `1536×10×10`, один общий GeM и отдельный BNNeck каждой полосы.
- **Гипотеза:** локальные полосы добавят различимость фар, крыши и нижней части кузова, не разрушая уже сильный глобальный дескриптор EXP-048.
- **Контроль смешивания:** глобальный вектор имеет норму 1; весь блок из пяти локальных векторов — норму `0,5`. После общей L2-нормализации это даёт 80% веса глобальному cosine и 20% локальному блоку. Нулевой вес локального блока в точности воспроизводит родителя.
- **Почему backbone заморожен:** первая абляция проверяет только пользу GLPE. ConvNeXt, CLIP-проекция и глобальный BNNeck загружаются из EXP-048 и не меняют ни параметры, ни running statistics. Если результат полезен, отдельный дочерний эксперимент проверит разморозку; OT-GFAM будет ещё одним отдельным изменением.

## Соответствие статье

Из доступного авторского кода используются общий `GeM(p=3)`, разбиение `2+3`, пять независимых BNNeck и L2 каждой части. Последняя строка карты при делении на три отбрасывается, как в авторском `convnext_part_model.py`. Глобальная ветка остаётся CLIP-веткой EXP-048, поэтому это гибрид, а не попытка выдать его за точную репликацию статьи. OT-GFAM в EXP-132 отсутствует.
