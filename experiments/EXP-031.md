# EXP-031 · EVA02-L/14 CLIP

## Идея
- **Родитель:** EXP-020 (тег `exp-020`).
- **Изменение (одно):** визуальная часть EVA02-L/14 CLIP (`merged2b_s4b_b131k`) вместо LAION-2B ViT-L/14; рецепт EXP-020 без изменений.
- **Гипотеза:** EVA02 до CLIP-обучения предобучен восстановлением признаков по маске (MIM). Такие бэкбоны сильнее переносятся на задачи мелких различий, а по размеру и вычислениям EVA02-L близок к ViT-L/14. Ожидаем прирост mAP@10 при сопоставимой скорости.
- **Пакет изменений:** архитектура (RoPE, SwiGLU) и веса неразделимы.

## Запуск
- **Тег:** `exp-031` · дифф с родителем: `git diff exp-020 exp-031`
- **Внешние веса:** [HF `timm/eva02_large_patch14_clip_224.merged2b_s4b_b131k`](https://huggingface.co/timm/eva02_large_patch14_clip_224.merged2b_s4b_b131k), `open_clip_model.safetensors`, ревизия `bf4190eb65dd5204ffb03e980108beb1200e0873`, MIT; sha256 — в конфиге и [DATA.md](../DATA.md).
- **Потоковость:** да.
- **Конфиг:** `configs/exp031_eva02_l14.yaml`
- **Команда:** `CONFIG=configs/exp031_eva02_l14.yaml GPU=2 SEED_GPUS=2 PARALLEL_SEEDS=0 PREPARED_ENV=/workspace/yslfalcon_runs/EXP-030/.venv setsid nohup bash scripts/pod_train_job.sh > status/job.log 2>&1 < /dev/null &`; в серии — `scripts/pod_series_job.sh`, последним.
- **Протокол:** `configs/val_v2.yaml`, фолд 0; обучение на фолдах 1–3; фолд 4 не трогается.
- **Сиды:** 0, 1, 2 — по одному на GPU 2: на сид нужно около 55 ГБ, у GPU 1 и 3 столько свободной памяти нет.
- **Окружение:** второй под, H200 (память делится с чужими контейнерами); Python 3.13.7, torch 2.10.0+cu130, open_clip 3.3.0, timm 1.0.29.
- **Проверка до запуска:** визуальная часть — timm-башня, выход 768, нормализация OpenAI, 304,1 млн параметров. На батче 128 в bf16 градиенты конечные, шаг 0,47 с (ViT-L/14 — 0,24 с), пик 55 ГБ. Перезагрузка без публичных весов, как на инференсе, даёт тот же выход.
- **Решение:** против EXP-020 (0,785 ± 0,008), как у EXP-030.

## Вывод
- **Решение:** accepted по качеству против EXP-020: прирост +0,056 больше разброса сидов (0,008). Парный bootstrap — после получения AP EXP-020.
- **Почему:** лучше DFN-2B (0,837), хуже SigLIP 2 (0,857); лучший срез маленьких рамок из всех (0,836). F1_strict выше остальных (0,081).
- **Что дальше:** не в приоритете — по качеству уступает SigLIP 2, обучается вдвое дольше ViT-L/14. Скорость перемерить на свободном CPU, если EVA02 понадобится.
