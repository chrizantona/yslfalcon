# EXP-008 · EXP-003 с головой CosFace

## Идея
- **Родитель:** EXP-003 (тег `exp-003`)
- **Изменение (одно):** линейный классификатор ID-loss заменён косинусным с отступом CosFace: логит своего класса s·(cos θ − m), s = 30, m = 0,35. BNNeck, triplet loss, сглаживание меток 0,1 и остальной рецепт без изменений; на инференсе модель та же, голова выбрасывается.
- **Гипотеза:** то же, что в EXP-007: ID-loss оптимизирует косинус, по которому идёт поиск, а отступ сжимает кадры машины вокруг её центра. Отступ CosFace постоянен по косинусу и не зависит от угла, поэтому обычно сходится стабильнее ArcFace — сравнение двух покажет, важен ли вид отступа.
- **Пакет изменений:** нет. m — значение из статьи, s = 30 выбран заранее: нижняя граница из статьи CosFace для ~925 классов около 9. По фолду 0 не подбирались.

## Запуск
- **Тег:** `exp-008`. Запущен с одного коммита с EXP-007; отличие от родителя видно в конфигах: `git diff --no-index configs/exp003_clip_vitb16_bot_30ep.yaml configs/exp008_clip_vitb16_bot_30ep_cosface.yaml`
- **Конфиг:** `configs/exp008_clip_vitb16_bot_30ep_cosface.yaml`
- **Команда:** `CONFIG=configs/exp008_clip_vitb16_bot_30ep_cosface.yaml GPU=<id> setsid nohup bash scripts/pod_train_job.sh > status/job.log 2>&1 < /dev/null &`
- **Протокол:** `val_v1` — обучение на фолдах 1–3, оценка на фолде 0 после 30 эпох (промежуточная на 20-й); фолд 4 не используется
- **Сиды:** 0, 1, 2 — параллельно на одном GPU
- **Окружение:** 1× H200 на общем поде, torch 2.10.0+cu130
