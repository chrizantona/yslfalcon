# EXP-070 · SigLIP 2 + SupCon: температура 0,1

## Идея
- **Родитель:** EXP-053 (тег `exp-053`) — рецепт EXP-042 с SupCon (τ 0,07); его суп EXP-054 — лучший кандидат.
- **Изменение (одно):** температура SupCon 0,1 вместо 0,07.
- **Гипотеза:** τ ни разу не подбирали (0,07 — значение по умолчанию из статьи SupCon). Более мягкая τ сглаживает вклад трудных негативов; при 3 позитивах на якорь это может стабилизировать обучение.
- **Пакет изменений:** нет.

## Запуск
- **Тег:** `exp-070` · дифф с родителем: `git diff exp-053 exp-070`
- **Внешние веса и данные:** как у EXP-053 (SigLIP 2 So400m/14, претрейн EXP-040 `b155ab652c084d75bf3054d188e01313.pt`); новых загрузок нет.
- **Потоковость:** да.
- **Конфиг:** `configs/exp070_siglip2_supcon_t010.yaml`
- **Команда:** очередь `scripts/queues/pod_a_supcon_round2.txt` через `scripts/pod_queue_job.sh`; три сида параллельно на GPU 1/2/3.
- **Протокол:** `configs/val_v2.yaml`, фолд 0; обучение на фолдах 1–3; фолд 4 не трогается.
- **Сиды:** 0, 1, 2.
- **Окружение:** второй под (rougenn), H200; venv EXP-030.
- **Решение:** против EXP-053 (0,8895 ± 0,0017) — прирост больше разброса сидов или парный bootstrap по машинам с CI выше нуля (AP EXP-053 — в Release `exp-054`); отдельно 45·mAP@10 + 10·отказ. Если принят — суп трёх сидов против EXP-054.

## Вывод
- **Решение:** accepted — CI выше нуля, прирост (0,0032) больше разброса сидов (0,0017); самый малый разброс в серии (0,0010).
- **Почему:** по температуре зависимость с максимумом при τ 0,1: 0,05 — 0,8884 (EXP-071), 0,07 — 0,8895 (EXP-053), 0,1 — 0,8927, 0,15 — 0,8907 (EXP-080). Прирост есть на всех срезах, больше всего — на ракурсах, которых нет на других камерах.
- **Что дальше:** суп сидов — EXP-079 (0,8961, против EXP-054 inconclusive); для финального переобучения на фолдах 0–3 — рецепт с τ 0,1.
