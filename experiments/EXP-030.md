# EXP-030 · ViT-L/14 с весами DFN-2B

## Идея
- **Родитель:** EXP-020 (тег `exp-020`).
- **Изменение (одно):** веса CLIP ViT-L/14 DFN-2B (Apple) вместо LAION-2B. Архитектура та же, но DFN обучен с QuickGELU, поэтому модель `ViT-L-14-quickgelu`; рецепт EXP-020 без изменений.
- **Гипотеза:** переход ViT-B → ViT-L дал +0,075, то есть качество предобученных признаков — главный рычаг. DFN-2B отобран фильтрующей сетью и сильнее LAION-2B на zero-shot, поэтому при той же архитектуре и скорости должен дать выше mAP@10.
- **Пакет изменений:** нет; скорость инференса не меняется.

## Запуск
- **Тег:** `exp-030` · дифф с родителем: `git diff exp-020 exp-030`
- **Внешние веса:** [HF `apple/DFN2B-CLIP-ViT-L-14`](https://huggingface.co/apple/DFN2B-CLIP-ViT-L-14), `open_clip_pytorch_model.bin`, ревизия `13d68e40771108ec1812f566404e8c6f7de85f67`, лицензия apple-amlr; sha256 — в конфиге и [DATA.md](../DATA.md).
- **Потоковость:** да, каждый запрос независимо.
- **Конфиг:** `configs/exp030_dfn2b_vitl14.yaml`
- **Команда:** `CONFIG=configs/exp030_dfn2b_vitl14.yaml GPU=1 SEED_GPUS=1,3,2 PREPARED_ENV=/workspace/yslfalcon_runs/EXP-030/.venv setsid nohup bash scripts/pod_train_job.sh > status/job.log 2>&1 < /dev/null &`; в серии — `scripts/pod_series_job.sh`.
- **Протокол:** `configs/val_v2.yaml`, фолд 0; обучение на фолдах 1–3; фолд 4 не трогается.
- **Сиды:** 0, 1, 2.
- **Окружение:** второй под, H200 (GPU 1/3/2, память делится с чужими контейнерами); Python 3.13.7, torch 2.10.0+cu130, open_clip 3.3.0, `requirements*.txt`.
- **Проверка до запуска:** 45 тестов прошли. Выход 768, нормализация OpenAI, 304,0 млн параметров. На батче 128 в bf16 градиенты конечные, шаг 0,24 с, пик около 40 ГБ. Перезагрузка без публичных весов, как на инференсе, даёт тот же выход.
- **Решение:** против EXP-020 (0,785 ± 0,008): прирост больше разброса сидов или парный bootstrap по машинам с CI выше нуля. Для bootstrap нужны AP запросов EXP-020 из релиза товарища.
