# Замер скорости на RTX A5000 (18.09.2026)

Сырые результаты `reid.benchmark` на арендованном поде с той же видеокартой, что у организаторов. Сводная таблица и выводы — в разделе «Скорость на RTX A5000» [README](../../README.md). Это исключение из правила «артефакты не коммитить»: файлы маленькие (~130 КБ), и по ним защищается выбор точности fp16 для инференса.

- **Железо** (`hardware.txt`): RTX A5000 24 ГБ, драйвер 580.159.04, 2× Xeon Gold 6342 (2,8 ГГц, турбо 3,5 ГГц). У организаторов — 2× Xeon Gold 6338 (2,0 / 3,2 ГГц), поэтому CPU-часть времени на одно ТС у них будет немного больше.
- **Окружение** (`logs/env.txt`): Python 3.13.7, torch 2.10.0+cu126 (CUDA 12.6), open_clip 3.3.0, timm 1.0.29 — как в Docker (`requirements-inference.txt`).
- **Методика:** `reid.benchmark` из коммита `8650626`, полный цикл на одно ТС от чтения кадра до L2-нормализации, 50 прогревов и медиана 300 прогонов; FPS — лучший из батчей 1/8/16/32, не меньше 10 с на каждый; кадры — 1 110 запросов `test_query.csv`, датасет — `configs/bench_data.yaml`.
- **Модели:** скорость зависит только от архитектуры и точности. Поэтому каждая модель — публичный бэкбон плюс свежий BNNeck, сохранённые чекпоинтом формы обученного (`logs/speed_ckpt.log`), и замер идёт через `--checkpoint`, как у обученных супов. Публичные веса скачаны `scripts/fetch_external.sh` с проверкой sha256 (`logs/weights.log`).
- **Конфиги:** для записей fp16/fp32 из репозитория использованы исходные конфиги (`configs/exp043_…`, `exp042_…`, `exp037_…`, `exp047_…`, `exp048_…`, `exp031_…`, `exp016_…`). Варианты другой точности лежат в `configs/`: это те же конфиги с заменённой строкой `precision`.
- **Скрипт:** `a5000_bench.sh` — одноразовый, запускался на поде после установки окружения.
