# EXP-188 · Претрейн на VERI-Wild с заменой фона

## Идея
- **Родитель:** EXP-040 (тег `exp-040`) — претрейн SigLIP 2 So400m на VERI-Wild test (10 000 машин, 138 518 кропов), с которого стартуют все наши лучшие модели (`b155ab…`).
- **Изменение (одно):** аугментация на претрейне. С вероятностью 0,5 машина по своей маске SAM переносится на случайное окно кадра наших обучающих фолдов 1–3 (тот же банк из 3 000 окон, что в EXP-185), дальше — обычные аугментации. Маски VERI-Wild — `reid.sam_masks --external veriwild_test`: рамка — весь кроп, точка — его центр, из трёх масок берётся лучшая по оценке SAM из накрывающих точку; маска расширена на 1,5% стороны.
- **Зачем именно на претрейне:** в EXP-185 замена фона на дообучении стоила −0,013 — модель теряла контекст стоянки, который на наших кадрах полезен. На претрейне цель другая: VERI-Wild — другие камеры и сцены, там фон — чистая помеха, и модель, привыкшая не опираться на фон VERI-Wild, может лучше переносить признаки машины. На дообучении фон наших стоянок остаётся — EXP-189 дообучается как обычно.
- **Инференс не меняется:** SAM нужен только для масок обучения.
- **Риск:** банк фонов — кадры наших стоянок, модель на претрейне увидит их как фон чужих машин; утечки нет (фолды 1–3 — обучающие), но распределение фона меняется.
- **Пакет изменений:** нет.

## Запуск
- **Тег:** `exp-188` · дифф с родителем: `git diff exp-040 exp-188`
- **Данные:** маски `/dev/shm/ext/veriwild_test/masks` — `CUDA_VISIBLE_DEVICES=1 PYTHONPATH=src python3 -m reid.sam_masks --data-config configs/data.yaml --external veriwild_test --shard 0/2` (и шард 1/2 на GPU 2), системный python пода; стадия `background` задачи проверяет, что маски есть для всех кропов.
- **Конфиг:** `configs/exp188_pretrain_veriwild_background.yaml`; чекпоинт `0a535fe7…` назначен заранее, с него стартует EXP-189.
- **Команда:** из копии репо в `/workspace/yslfalcon_runs/EXP-188/`: `CONFIG=configs/exp188_pretrain_veriwild_background.yaml GPU=1 PREPARED_ENV=/workspace/yslfalcon_runs/EXP-030/.venv setsid nohup bash scripts/pod_train_job.sh > status/job.log 2>&1 < /dev/null &`
- **Протокол:** обучение только на VERI-Wild; оценка на фолде 0 для справки; фолд 4 не трогается.
- **Сиды:** 0, как у EXP-040.
- **Окружение:** второй под (rougenn), H200; GPU 1–2 (GPU 3 по просьбе оставлена свободной, GPU 0 — чужой процесс).
- **Решение:** по EXP-189 — претрейн оценивается тем, что он даёт дообученной модели.
