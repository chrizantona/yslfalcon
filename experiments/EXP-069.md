## Вывод

- **Решение относительно явного родителя EXP-068:** rejected. Δ -0.006683, 95% CI [-0.012095; -0.001047]. Bootstrap: 2000 выборок по `vehicle_id`, seed 0; AP предварительно сверены с mAP@10.
- **Против лучшего EXP-054:** rejected, Δ -0.032572, 95% CI [-0.042906; -0.023024]. EXP-054 остаётся лучшим; решение по слабому родителю не продвигает эту модель в финальные кандидаты.
- **Интерпретация:** Полная предложенная архитектура проверена. Итоговый AFEM residual/main norm ratio 0,494…0,508, scale 0,188…0,193; auxiliary loss 17,53…17,59, GeM p 2,913…2,943. Все прогоны конечны. Вклад AFEM отделён сравнением с объединением EXP-068; дополнительное сравнение с EXP-066 показывает вклад CNN при AFEM.
- **Дополнительное сравнение с EXP-066:** Δ -0.002360, 95% CI [-0.007504; +0.003433], inconclusive только в рамках этого сравнения.
- **Далее:** новых изменений/супа по результатам этой серии не запускаем; фолд 4 не использован.
