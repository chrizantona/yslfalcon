# EXP-207 · Уверенность, слепая к дублям, и диагностика теста

## Идея
- **Родитель:** EXP-206 · опирается на пороги EXP-202.
- **Что обнаружено:** на реальном тесте порог 7,0446 отказывает лишь в 5,5% запросов, хотя по ТЗ пары нет у 20%. Причина не в модели: распределение z на тесте квантиль в квантиль совпадает с **полной** галереей фолда 4 (доля ниже порога 5,7% против 4,9%), где у каждого запроса пара есть, и совершенно не похоже на нашу постановку теста (22,7%). В полной галерее **у 94% запросов топ-1 — это junk**, кадр той же машины с той же камеры, почти дубль из той же серии; он и задирает z.
- **Две картины мира, которые z не различает:**
  - **A** — у каждого тестового запроса действительно есть кросс-камерная пара, и 5,5% отказов правильные;
  - **B** — у запросов без пары их собственный кадр с их же камеры остался в галерее; тогда они выглядят максимально уверенными, наш отказ к ним слеп, TNR уходит в ноль и мы теряем около 2,5 балла из 10.
- **Изменение:** уверенность считается по лучшему кандидату, который **не является почти-дублем** запроса: `conf = (max_{cos ≤ τ} cos − mean) / std`. Дубль (τ около 0,97) — это почти всегда тот же кадр с той же камеры.
- **Как проверяется:** сценарий B моделируется на фолде 4, где у нас есть метки: у каждой машины без пары в галерее остаётся только её кадр с одной камеры, и в запросах остаются только кадры с той же камеры. Обе уверенности считаются на обоих сценариях; затем победитель применяется к реальному тесту.
- **Диагностика:** если под новой уверенностью у теста появляется левая мода примерно на 20% запросов — мы в сценарии B, и она нас спасает. Если не появляется — в этом файле почти всё сматчено, и текущие 5,5% отказов верны.
- **Правило решения (записано до запуска):** новая уверенность берётся в сабмит, если в сценарии B она даёт заметно больший балл отказа, чем прежняя, **и** в сценарии A/C не проигрывает больше 0,005 балла. Диагностика теста решает, какой сценарий считать рабочим, но сам выбор уверенности от неё не зависит.
- **Пакет изменений:** `src/reid/duplicate_confidence.py`, тест `tests/test_duplicate_confidence.py`.

## Запуск
- **Тег:** `exp-207` · **Конфиг:** `configs/exp207_duplicate_confidence.yaml`
- **Команда:** `PYTHONPATH=src python -m reid.duplicate_confidence --val-config configs/val_v2.yaml --config configs/exp207_duplicate_confidence.yaml`
- **Обучения нет:** используются сохранённые эмбеддинги супа EXP-203 (фолд 4, полная галерея) и эмбеддинги сабмита.

## Результаты
Завершён 23.09.2026. Эмбеддинги супа EXP-203; балл отказа = 0,7·F1 + 0,3·TNR в центре плато своей кривой.

| Уверенность | Сценарий C (машина удалена, наш протокол) | Сценарий B (двойник с той же камеры остался) |
|---|---|---|
| Обычная z | **0,9122** (F1 0,901, TNR 0,937) | 0,6155 (F1 0,856, **TNR 0,053**) |
| Без дублей, τ = 0,95 | 0,8646 (TNR 0,843) | **0,7042** (TNR 0,336) |
| τ = 0,96 | 0,8737 | 0,6961 |
| τ = 0,97 | 0,8893 | 0,6866 |
| τ = 0,98 | 0,8995 | 0,6443 |

Сценарий B подтвердил опасение целиком: обычная уверенность видит **5,3% TNR**, то есть почти не отказывает там, где пары нет. Но и лечение слабое — медианы уверенности при τ = 0,95 в сценарии B: 8,35 у запросов с парой против 8,13 без пары, разделения почти нет. Причина в том, что кадр той же камеры — не обязательно почти-дубль: он из другой серии, косинус 0,90–0,96, и маска по косинусу его не ловит, зато срезает истинные кросс-камерные совпадения (медиана уверенности у сматченных падает с 9,32 до 8,35).

### Диагностика реального теста
Квантили уверенности (1%, 5%, 10%, 20%, 50%), модель одна и та же:

| Набор | Обычная z | Без дублей, τ = 0,95 | τ = 0,97 |
|---|---|---|---|
| Фолд 4, полная галерея (0% без пары) | 5,65 / 7,08 / 7,66 / 8,31 / 9,42 | 4,79 / 5,89 / 6,54 / 7,19 / 8,44 | 5,02 / 6,50 / 6,98 / 7,70 / 8,93 |
| Фолд 4, сценарий B (11,3% без пары) | 5,73 / 7,07 / 7,56 / 8,23 / 9,38 | 3,68 / 5,15 / 6,16 / 6,97 / 8,32 | 3,69 / 5,86 / 6,70 / 7,49 / 8,85 |
| **Реальный тест** | 5,52 / 6,86 / 7,61 / 8,36 / 9,35 | 4,24 / 5,39 / 6,02 / 6,91 / 8,38 | 4,65 / 5,84 / 6,61 / 7,55 / 8,92 |

Доля кадров с почти-дублем в галерее совпадает: 40,1% у теста против 38,8% у полной галереи фолда 4.

По обычной уверенности тест неотличим от полной галереи. По уверенности без дублей его нижние квантили лежат **между** двумя опорными наборами, ближе к сценарию B: линейная интерполяция по квантилям 1–20% даёт оценку доли «запросов без пары типа B» примерно **5–15%**. Оценка грубая — наборы машин разные, систематический сдвиг возможен.
