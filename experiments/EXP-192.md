# EXP-192 · Ракурс из токенов нашей модели вместо CLIP

## Идея
- **Родитель:** EXP-191 (тег `exp-191`) — лучший пайплайн на обоих фолдах: суп EXP-164 + поправка на ракурс из CLIP ViT-B/16 (δ = 0,07), без реранкера; фолд 0 — 0,927871, фолд 4 — 0,893539.
- **Изменение (одно):** откуда берётся ракурс. Вместо CLIP — softmax-голова на токенах патчей нашей же модели (выход `trunk.forward_features`, из которого пулинг строит эмбеддинг; на инференсе они уже посчитаны — голова почти бесплатна). Два варианта признаков: средний токен и средние по четырём четвертям сетки 16 × 16. Голова учится на фолдах 1–3 по меткам CLIP. δ = 0,07 и порог 7,2429 — без изменений.
- **Почему не на эмбеддинге:** голова на итоговом эмбеддинге в EXP-190 совпала с CLIP лишь на 72% — эмбеддинг ReID учится не зависеть от ракурса; в токенах до пулинга ракурс ещё есть. Совместное обучение головы ракурса с моделью тянуло бы эмбеддинг в две стороны и требовало бы заново учить суп.
- **Пакет изменений:** нет.

## Запуск
- **Тег:** `exp-192` · **Конфиг:** `configs/exp192_view_tokens.yaml`
- **Команда:** `PYTHONPATH=src python -m reid.view_tokens --data-config configs/data.yaml --val-config configs/val_v2.yaml --config configs/exp192_view_tokens.yaml` на GPU 1; эмбеддинги и уверенность фолдов 0 и 4 — из кэша EXP-190.
- **Решение (заранее):** голова заменяет CLIP, если на фолде 0 её прирост не меньше ~80% прироста CLIP (+0,0134 для супа) и совпадение с CLIP на фолдах 0 и 4 не ниже ~90%. Фолд 4 — только проверка (четвёртый просмотр, ничего не подбирается).
