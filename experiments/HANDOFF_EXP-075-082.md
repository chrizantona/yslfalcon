# Передача EXP-075…078 и EXP-082

Серия выполнена 19.09.2026 на третьем поде с NVIDIA H200. Код EXP-075…078 зафиксирован коммитом `37a114ee6b760a25d98a11de64ff5871f07632cd` и тегами `exp-075`…`exp-078`; EXP-082 — коммитом `db687d8` и тегом `exp-082`. До запуска окружение прошло 70 тестов. ## Артефакты

Приватный [Release `exp-082`](https://github.com/chrizantona/yslfalcon/releases/tag/exp-082) содержит:

- пять архивов результатов со всеми 24 матрицами эмбеддингов, per-query AP, метриками, логами, срезами и снимком исполнявшегося кода;
- 11 исходных FP32 checkpoint: три EXP-075, три EXP-076, один EXP-077, три EXP-078 и суп EXP-082;
- `manifest.json`, `checkpoint_manifest.json`, `SHA256SUMS`, отдельные квитанции архивов и служебные логи.

До публикации каждый `.npy` проверен по SHA256, заголовку, форме, типу float16, конечности и L2-норме; AP из `per_query_ap.csv` воспроизводит записанный mAP@10. После скачивания архивы и каждый внутренний файл повторно проверены локально. GitHub digest и размер каждого Release-asset сверены после загрузки. Токен GitHub на под не передавался.
