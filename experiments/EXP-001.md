# EXP-001 · CLIP ViT-B/16, дообучение по рецепту ReID

## Идея
- **Родитель:** EXP-000 (тег `exp-000`)
- **Изменение:** дообучение визуальной части CLIP ViT-B/16 вместо готовых эмбеддингов
- **Гипотеза:** обучение на своих машинах с позитивами с других камер поднимет сходство «та же машина, другая камера» над самыми похожими чужими машинами; ожидаем заметный прирост mAP относительно 0,312
- **Пакет изменений:** да, рецепт целиком — BNNeck, ID-loss со сглаживанием меток 0,1, batch-hard triplet с запасом 0,3, PK-сэмплер 32 × 4 с чередованием камер, AdamW с разогревом и косинусным затуханием, flip, сдвиг-кроп, random erasing. Это первый обучаемый бейзлайн, вклад частей проверяется следующими экспериментами.

## Запуск
- **Тег:** `exp-001` · дифф с родителем: `git diff exp-000 exp-001`
- **Конфиг:** `configs/exp001_clip_vitb16_bot.yaml`
- **Команда:** `CONFIG=configs/exp001_clip_vitb16_bot.yaml GPU=<id> setsid nohup bash scripts/pod_train_job.sh > status/job.log 2>&1 < /dev/null &`
- **Протокол:** `val_v1` — обучение на фолдах 1–3, оценка на фолде 0 после 120 эпох; промежуточные оценки каждые 20 эпох нужны только для кривой обучения; фолд 4 не используется
- **Сиды:** 0, 1, 2 — параллельно на одном GPU
- **Окружение:** 1× H200 на общем поде, torch 2.10.0+cu130

## Вывод
- **Решение:** accepted — новый бейзлайн
- **Почему:** прирост mAP +0,333, доверительный интервал целиком выше нуля, разброс по сидам 0,007
- **Что дальше:** главный кандидат — бюджет обучения: 30 эпох вместо 120 (одно изменение). Отдельный эксперимент — меньший lr бэкбона.
