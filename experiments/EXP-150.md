# EXP-150 · Ансамбли сохранённых эмбеддингов

## Идея
- **Родитель:** EXP-090 (тег `exp-090`) — суп трёх сидов EXP-089: mAP@10 0,8976, отказ 0,9202.
- **Изменение (одно):** вместо одной модели — среднее L2-нормированных эмбеддингов нескольких, с повторной нормировкой. Шесть заранее заданных составов: сам суп (база), три сида одного рецепта, два и три супа разных рецептов, суп плюс модель другой башни (/16 при 256), и смешанный состав из трёх.
- **Зачем, если ансамбль нельзя сдать:** нельзя — это N прямых проходов и N×1 715 МБ при лимите 2 ГБ. Но ансамбль отвечает на два вопроса: сколько ещё качества вообще осталось в наших моделях и стоит ли брать его учителем для дистилляции. Учителю ограничения не важны, он живёт только во время обучения.
- **Гипотеза:** ансамбль обычно сильнее супа, когда участники различаются. Самый интересный состав — с башней /16 при 256 (EXP-121): у неё другой патч, другое разрешение и другой претрейн, то есть максимальная непохожесть при равном качестве.
- **Пакет изменений:** нет; код — `reid.ensemble` расширен списком произвольных каталогов эмбеддингов.

## Запуск
- **Тег:** `exp-150` · дифф с родителем: `git diff exp-090 exp-150`
- **Внешние веса и данные:** нет; вход — сохранённые эмбеддинги EXP-054, EXP-079, EXP-089, EXP-090 и EXP-121.
- **Потоковость:** да, но состав из N моделей стоит N прямых проходов.
- **Конфиг:** `configs/exp150_ensembles.yaml`
- **Команда:** `PYTHONPATH=src python -m reid.ensemble --data-config configs/data.yaml --val-config configs/val_v2.yaml --config configs/exp150_ensembles.yaml`
- **Протокол:** `configs/val_v2.yaml`, фолд 0; фолд 4 не трогается. Порог отказа пересчитывается для каждого состава.
- **Сиды:** не применимо.
- **Окружение:** второй под (rougenn); обучения нет, считается минуты.
- **Решение:** парный bootstrap по машинам против базы (одиночный суп EXP-090). Результат не идёт в сдачу — он нужен как ориентир и как выбор учителя.
