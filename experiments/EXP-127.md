# EXP-127 · OT-GFAM + GLPE с ReLU-GeM: претрейн на VERI-Wild

## Идея
- **Родитель:** EXP-125 (`exp-125`) — ReLU-контроль на LCT, mAP@10 `0,460120`.
- **Изменение:** только обучающие данные: вместо folds 1–3 используется публичный VERI-Wild test — 138 517 кадров, 10 000 машин и 162 камеры. Архитектура, differential lr, loss, аугментации и 60-эпоховый cosine-рецепт совпадают с EXP-125.
- **Гипотеза:** ReLU оказался лучшим из трёх способов сделать signed LayerNorm-карту пригодной для GeM, но на малом LCT train новые слои переобучились. Большой внешний набор должен обучить OT-GFAM/GLPE до LCT-адаптации.

## Запуск
- **Тег:** `exp-127`; дифф с родителем: `git diff exp-125 exp-127`.
- **Конфиг:** `configs/exp127_ot_gfam_relu_veriwild.yaml`.
- **Данные и веса:** те же публичные VERI-Wild test и ConvNeXt-L ImageNet-22K, что в EXP-126; источники, лицензии и sha256 — в [DATA.md](../DATA.md). LCT train и fold 4 не используются.
- **Сид:** 0; PK 8×4; остальной рецепт совпадает с EXP-125.
- **Команда:** `CONFIG=configs/exp127_ot_gfam_relu_veriwild.yaml GPU=0 setsid nohup bash scripts/pod_train_job.sh > status/job.log 2>&1 < /dev/null &`.
- **Чекпоинт:** `29c54de75dd7402eac0d4bc5e4aa1b59.pt`; остаётся на поде.

## Результаты

Первый перенос на `val_v2` после 40 эпох дал:

| Метрика | Значение |
|---|---:|
| mAP@10 | 0,320334 |
| R1 / R5 | 0,272647 / 0,527704 |
| score отказа | 0,512107 |
| F1 / TNR | 0,368512 / 0,847162 |
| полный mAP / mINP | 0,341910 / 0,294574 |

К 40-й эпохе train loss снизился до `20,8659`, accuracy выросла до `0,3900`, то есть оптимизация шла, но перенос оказался хуже прямого обучения EXP-125 (`0,460120`). Прогон остановлен после 41-й эпохи; checkpoint не сохранялся.

## Вывод
- **Решение:** rejected (early stop). Претрейн на VERI-Wild не исправил перенос, а [аудит оригинальной статьи](OT_GFAM_ORIGINAL_PAPER_AUDIT.md) показал, что сама реконструкция не соответствует опубликованной архитектуре.
