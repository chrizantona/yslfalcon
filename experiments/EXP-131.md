# EXP-131 · Официальный ConvNeXt-L + GLPE checkpoint без дообучения

Статус `reference`: публичный авторский checkpoint оценивается как есть и в сравнениях с кандидатами не участвует.

## Идея
- **Родитель:** нет; это внешний публичный checkpoint из репозитория оригинальной статьи.
- **Что проверяем:** реальный перенос опубликованных весов на LCT `val_v2`, без нашего обучения и без изменения BN statistics.
- **Что внутри:** полный ConvNeXt-L, stride последнего stage = 1, общий GeM, шесть BNNeck и concat `6×1536`. Проверка 379 ключей показала отсутствие любых OT-GFAM/ONN параметров. Встроенный config: VeRi-776, 775 train ID, 256×256, seed 42, 60 эпох, Adam `3,5e-4`, warm-up 10, batch 32 и четыре кадра на ID; `best_map=0,872111`.
- **Гипотеза:** если официальный GLPE переносится заметно лучше ImageNet-инициализации EXP-130, главным недостающим фактором прежней ветки был доменный VeRi-претрейн. Это всё ещё не проверка OT-GFAM, потому что авторы его веса и код не опубликовали.
