# EXP-000 · CLIP ViT-B/16 без обучения, проверка пайплайна

Статус `reference`: проверка сквозного пайплайна (данные → протокол → оценка → файлы сдачи), в сравнениях не участвует.

## Идея
- **Родитель:** нет
- **Изменение:** готовые эмбеддинги CLIP ViT-B/16 (LAION-2B, `laion2b_s34b_b88k`), вход 224×224, вырезка по рамке
- **Гипотеза:** пайплайн собирается и выдаёт корректные файлы сдачи; метрики на уровне нулевых результатов из EDA
- **Пакет изменений:** нет

## Запуск
- **Тег:** `exp-000` (прогон сделан до первого коммита кода)
- **Конфиг:** `configs/exp000_clip_zeroshot.yaml`
- **Команда:** `setsid nohup bash scripts/pod_job.sh > status/job.log 2>&1 < /dev/null &` из папки прогона на поде
- **Протокол:** `val_v1`, фолд 0: 309 машин, 1137 запросов, 789 снимков gallery; для отказа из gallery убраны 93 машины
- **Сиды:** не нужны (без обучения, детерминированно)
- **Окружение:** 1× H200, Python 3.12, torch 2.10.0+cu130, open-clip-torch 3.3.0
- **Время:** 4,7 мин на весь прогон; вырезка 11 416 рамок шла параллельно с оценкой

### Сдача на публичном тесте
- `embeddings.npy` (1860 × 512, float32), `submission.csv`, `candidates.csv` — проверка формата пройдена, ранжирование воспроизводится из эмбеддингов.
- При пороге 2,708 отказ у 5,7% запросов, принято 3360 кандидатов. В публичном тесте у каждого запроса есть совпадение, поэтому отказов мало.
