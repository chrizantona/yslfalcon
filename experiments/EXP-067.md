# EXP-067 · osnet_ain

Статус: **running**. План и контрольные сравнения: [PLAN_EXP-065-069.md](PLAN_EXP-065-069.md).

## Идея
- **Родитель:** EXP-054 (тег `exp-054`)
- **Изменение (одно):** ImageNet OSNet-AIN x1.0 + GeM + 512D projection; EXP-054 training recipe.
- **Гипотеза:** OSNet даёт независимый дескриптор деталей автомобиля и проверяет достаточность этой ветви отдельно.
- **Пакет изменений:** новый бэкбон вместе с ImageNet-нормализацией, GeM и проекцией; единая замена ветви.

## Запуск
- **Тег:** `exp-067` · дифф с родителем: `git diff exp-054 exp-067`
- **Внешние веса и данные:** OSNet-AIN x1.0, ImageNet; официальный автор Kaiyang Zhou, MIT, закреплённые URL/ревизия/sha256 в [DATA.md](../DATA.md).
- **Потоковость:** да, независимый forward каждого снимка; глобальные AFEM gates общие для изображений, другие запросы не используются.
- **Конфиг:** `configs/exp067_osnet_ain.yaml`
- **Команда:** `CONFIG=configs/exp067_osnet_ain.yaml GPU=3 SEED_GPUS=3,2,0 PREPARED_ENV=/tmp/EXP-065/.venv setsid nohup bash scripts/pod_train_job.sh > status/job.log 2>&1 < /dev/null &`
- **Протокол:** `val_v2`, `configs/val_v2.yaml`, фиксированные фолды; train 1/2/3, dev 0; фолд 4 не используется.
- **Сиды:** 0, 1, 2
- **Окружение:** H200, отдельная Python 3.13.7 venv; закреплённые `requirements.txt` и `requirements-pod.txt`. Перед запуском — тесты и реальный batch 128 с конечными градиентами и проверкой VRAM.

Предзапусковая проверка H200: реальные crops train, P=32/K=4, три BF16 шага, все trainable gradients конечны; peak reserved 9 516 875 776 байт (8,86 ГиБ). FP16 batch 256 конечен, повтор запроса bit-identical, разница single/batch ≤0,000214. Строго загружены авторские ImageNet-веса с проверкой SHA256. 68 тестов прошли. Квитанция — `artifacts/EXP-067/launch/preflight.json`.

## Вывод
- **Решение:** running — обучение запланировано к старту после фиксации тега; метрик пока нет; принятие только по paired bootstrap AP по машинам (95% CI выше нуля) либо достоверному превышению разброса сидов.
- **Почему:** результат ещё не получен; эффект дополнительного обучения контролируется EXP-065.
- **Что дальше:** три сида, FP16 quality check каждого сида, `reid.benchmark`, срезы и AP/эмбеддинги; публикация архивов в приватный Release `yslfalcon`.
