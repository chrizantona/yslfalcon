## Вывод
- **Решение:** rejected как самостоятельная замена EXP-054: все три сида значительно хуже. Paired bootstrap с опубликованным EXP-054 подтверждает падение: Δ −0,793035, 95% CI [−0,820068; −0,766690], 2000 выборок по машинам, seed 0.
- **Почему:** mAP@10 0,057206 / 0,175477 / 0,069904; среднее 0,100862 против 0,893897, Δ −0,793035. Разброс 0,064929. FP16 воспроизводит результат (среднее 0,100848, Δ к FP32 −0,000014). ID loss в конце 11,81…12,83, accuracy по logits с ArcFace-margin = 0 у всех сидов: этот замороженный рецепт не обучил качественную отдельную CNN. Причина плохой сходимости отдельно не установлена; результат не доказывает бесполезность CNN в объединении.
- **Что дальше:** Серия EXP-065/066/068/069 завершена 19.09: добавление CNN к семантическому контролю (068 против 065) и к AFEM (069 против 066) — inconclusive; к лучшему EXP-054 все варианты хуже. Все результаты сохранены. Измерение RTX A5000 для новой архитектуры ещё не выполнено.
