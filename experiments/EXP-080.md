## Вывод
- **Решение:** inconclusive против EXP-070.
- **Почему:** максимум mAP@10 по температуре — при τ 0,1; при 0,15 уже ниже, разброс сидов больше (0,0025). Отказ с ростом τ понемногу растёт (0,903 → 0,909 → 0,914 → 0,917), но это десятые доли балла.
- **Что дальше:** τ 0,2 (EXP-081) — для полноты кривой; рецепт — τ 0,1.
