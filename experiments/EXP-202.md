# EXP-202 · Порог отказа по leave-one-fold-out

## Идея
- **Родитель:** EXP-164; методика — EXP-178 (`reid.calibrate_refusal`, одна галерея, официальный F1, плато вокруг оптимума).
- **Задача:** дать финальной модели порог отказа, когда dev-фолда больше нет. Порог 7,2429 подобран на фолде 0 моделью, обученной на 924 машинах, и после EXP-201 перестаёт быть верным по двум причинам сразу: фолд 0 уходит в обучение, а сам порог дрейфует с объёмом данных (308 → 6,836; 616 → 6,998; 924 → 7,251).
- **Что делается:** пять честных калибровок. Четыре прогона рецепта на всех фолдах, кроме одного (`exp202_loo_fold{0,1,2,3}`), плюс сид 0 EXP-201, который по построению и есть прогон «без фолда 4». На отложенном фолде каждого прогона считается кривая балла отказа и берётся центр плато ±0,001.
- **Почему это работает:** порог — свойство рецепта при данном объёме данных, а не свойство фолда. Пять измерений вне выборки дают и центр, и разброс; ширина плато у нашей конфигурации 0,567 при допуске 0,005, поэтому промах на ±0,28 стоит меньше 0,05 балла.
- **Бонус:** пять честных оценок mAP@10 модели на 1 233 машинах — полноценная пятифолдовая кросс-валидация замороженного рецепта, вместо одной точки с фолда 4.
- **Правила (записаны до запуска):**
  - для оценки EXP-203 на фолде 4 берётся **медиана порогов фолдов 0–3** (фолд 4 в неё не входит — иначе порог был бы подобран на том же фолде, на котором считается результат);
  - порог финальной модели на всех пяти фолдах = медиана всех пяти + 0,03 (переход от сида к супу, измерено парой EXP-161 → EXP-164: 7,251 → 7,280) + поправка на дрейф 1 233 → 1 541 по той же кривой;
  - если разброс пяти порогов превысит 0,5, вывод — порог нестабилен, и тогда каждый прогон повторяется тремя сидами.
- **Фолды 0 и 4 здесь используются как обучающие данные, но ни одного решения о модели на них не принимается:** каждый фолд оценивается моделью, которая его не видела.
- **Пакет изменений:** нет; код не менялся.

## Запуск
- **Тег:** `exp-202` · **Конфиги:** `configs/exp202_loo_fold{0,1,2,3}.yaml` (обучение), `configs/exp202_calib_fold{0,1,2,3,4}.yaml` (калибровка)
- **Чекпоинты:** `82968b5df6694133aadecc743ee288f0_seed0.pt` (без фолда 0), `e5e98ba41a214512b47083db61f6838e_seed0.pt` (без 1), `70b4b4607d35413d93cff1b602a70f96_seed0.pt` (без 2), `b0fbdd7cb4664a9096ece520ac2bf681_seed0.pt` (без 3); для фолда 4 — `c15dcc3343b64259bd831b286822dde8_seed0.pt` из EXP-201.
- **Команда:** по одному `CONFIG=configs/exp202_loo_fold{k}.yaml GPU=3 bash scripts/pod_train_job.sh`, затем `PYTHONPATH=src python -m reid.calibrate_refusal --config configs/exp202_calib_fold{k}.yaml`; результат каждой калибровки сохраняется как `artifacts/EXP-202/fold{k}.json`.
- **Окружение:** второй под (rougenn), H200, GPU 3; venv EXP-030.

## Результаты
Завершён 23.09.2026. Пять калибровок, каждая на фолде, который её модель не видела.

| Оценка на фолде | mAP@10 (одна галерея) | Центр плато | Отказ при своём пороге | При старом 7,2429 |
|---|---|---|---|---|
| 0 | 0,925768 | 7,036 | 0,9762 | 0,9705 |
| 1 | 0,863136 | 6,868 | 0,9581 | 0,9482 |
| 2 | 0,913363 | 7,081 | 0,9604 | 0,9575 |
| 3 | 0,897407 | 7,053 | 0,9731 | 0,9695 |
| 4 | 0,899722 | 7,092 | 0,9568 | 0,9531 |

- **Разброс порогов 0,224** (6,868…7,092) — правило эскалации до трёх сидов не сработало. Медиана всех пяти **7,053**, медиана фолдов 0–3 — **7,045**.
- **Прогноз дрейфа вверх не подтвердился:** порог не вырос, а снизился против 7,2429. Прежние числа (6,836 / 6,998 / 7,251) считались по другому правилу и в другой постановке, сравнивать их с центром плато было нельзя. Измерение вместо экстраполяции окупилось.
- **Цена чужого порога мала:** старый 7,2429 стоил бы в среднем 0,005 балла отказа, максимум 0,010 (фолд 1) — ровно то, что обещала ширина плато.
- **Кросс-валидация рецепта:** среднее mAP@10 по пяти фолдам 0,8999 для одного сида на 1 232 машинах; фолды сильно разной сложности (0,863 на первом против 0,926 на нулевом), так что одна точка на фолде 4 мало что говорила бы.

## Выводы
- **Решение:** reference. Порог для модели на фолдах 0–3 — 7,0446; для модели на всех пяти фолдах — 7,053 + 0,03 (переход к супу) ≈ **7,08**.
- **Что дал приём:** пять честных измерений там, где отложенных данных не осталось. Тот же приём применён к поправке на ракурс в EXP-204.
