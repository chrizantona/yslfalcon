# EXP-129 · OT-GFAM + GLPE: общий lr большого претрейна

## Идея
- **Родитель:** EXP-128 (`exp-128`) — ReLU-GeM, 120 эпох, warm-up и multistep на VERI-Wild.
- **Изменение:** только группы оптимизатора: один Adam lr `3,5e-4` для бэкбона и новых слоёв вместо `1e-5` для ConvNeXt и `3,5e-4` для новых слоёв. Всё остальное совпадает с EXP-128.
- **Гипотеза:** полный lr соответствует записанному рецепту ветки статьи и может быстрее адаптировать ImageNet-бэкбон к vehicle ReID. Риск — разрушить полезные ImageNet-признаки; отдельный EXP нужен именно для измерения этого эффекта.

## Запуск
- **Тег:** `exp-129`; дифф с родителем: `git diff exp-128 exp-129`.
- **Конфиг:** `configs/exp129_ot_gfam_relu_veriwild_single_lr.yaml`.
- **Данные и веса:** публичные VERI-Wild test и ConvNeXt-L ImageNet-22K; источники и sha256 — в [DATA.md](../DATA.md). LCT train и fold 4 не используются.
- **Сид:** 0; PK 8×4; GPU 2.
- **Команда:** `CONFIG=configs/exp129_ot_gfam_relu_veriwild_single_lr.yaml GPU=2 setsid nohup bash scripts/pod_train_job.sh > status/job.log 2>&1 < /dev/null &`.
- **Чекпоинт:** `83290721959c4e57ae45eac35711d6d0.pt`; остаётся на поде.

## Результаты

Остановлен после контрольной 10-й эпохи warm-up. Loss остался на уровне случайного классификатора: `56,1624`, train accuracy `0`; все шесть веток совпали около `9,3604`. Одновременно показатели ReLU-GeM упали с `3,00` до `1,41–1,49`. При том же расписании differential-lr EXP-128 к 10-й эпохе достиг loss `39,6069` и accuracy `0,00535`.

## Вывод
- **Решение:** rejected (early stop) — общий lr `3,5e-4` разрушает обучение ImageNet-бэкбона; differential lr обязателен.
