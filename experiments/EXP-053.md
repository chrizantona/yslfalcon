# EXP-053 · SigLIP 2: SupCon вместо batch-hard triplet

## Идея
- **Родитель:** EXP-042 (тег `exp-042`) — принятый рецепт SigLIP 2: претрейн VERI-Wild, ArcFace с imprinting; его суп EXP-043 — лучший кандидат.
- **Изменение (одно):** supervised contrastive loss (Khosla et al., 2020; τ = 0,07, вес 1) вместо batch-hard triplet (отступ 0,3, вес 1) на признаке до BNNeck. Остальное как в EXP-042: ArcFace s = 30, m = 0,5 с imprinting, сглаживание 0,1, PK 32×4.
- **Гипотеза:** лосс взят из предложенной пользователем архитектуры ReID (ResNeXt101-IBN + TinyCLIP, CE + SupCon); целиком она не проверяется — обе её части на наших данных заметно слабее SigLIP 2. Triplet учится только на самой трудной паре в строке батча, SupCon — на всех 3 позитивах и 124 негативах сразу; сигнал плотнее и стабильнее. Ожидание скромное: рецепт EXP-042 нечувствителен к отступу, сглаживанию и lr (EXP-049…052). τ в описании не задан, 0,07 — значение по умолчанию из статьи SupCon.
- **Пакет изменений:** нет.

## Вывод
- **Решение:** accepted — интервал bootstrap выше нуля, прирост (0,0061) втрое больше разброса сидов (0,0017).
- **Почему:** SupCon учится на всех позитивах и негативах батча, а не на одной трудной паре; прирост есть на всех срезах, кроме маленьких рамок, больше всего — на обрезанных рамках и такси. Отказ чуть ниже (TNR 0,926 против 0,940), но по сумме баллов вариант лучше на 0,23.
- **Что дальше:** суп трёх сидов — EXP-054, сравнение с EXP-043.
