# yslfalcon

Сервис повторной идентификации автомобилей без номеров — задача «Фалькон Тех», ЛЦТ 2026: по снимку машины и её рамке найти ту же машину на других камерах или отказаться от ответа.

- Правила работы и эксперименты — [`AGENTS.md`](AGENTS.md)
- Данные, ответы организаторов, протокол — [`eda/KEY_FINDINGS.md`](eda/KEY_FINDINGS.md)
- Реестр текущего протокола — [`experiments/registry_val_v2.csv`](experiments/registry_val_v2.csv), карточки — `experiments/EXP-NNN.md`
- Переход на протокол `val_v2` и пересчёт — [`experiments/VAL_V2.md`](experiments/VAL_V2.md)
- Источники данных и весов с sha256, как повторить с нуля — [`DATA.md`](DATA.md)
