# yslfalcon

Сервис повторной идентификации автомобилей без номеров — задача «Фалькон Тех», ЛЦТ 2026: по снимку машины и её рамке найти ту же машину на других камерах или отказаться от ответа.

- Правила работы и эксперименты — [`AGENTS.md`](AGENTS.md)
- Данные, ответы организаторов, протокол — [`eda/KEY_FINDINGS.md`](eda/KEY_FINDINGS.md)
- Реестр текущего протокола — [`experiments/registry_val_v2.csv`](experiments/registry_val_v2.csv), карточки — `experiments/EXP-NNN.md`
- Переход на протокол `val_v2` и пересчёт — [`experiments/VAL_V2.md`](experiments/VAL_V2.md)
- Источники данных и весов с sha256, как повторить с нуля — [`DATA.md`](DATA.md)

## Ночной запуск ViT-L
Для прогона код копируется в `/workspace/yslfalcon_runs/EXP-NNN/`: `EXP-020`…`EXP-024`. `scripts/pod_night_job.sh` сначала запускает обучение ViT-L на GPU 1 и независимый fp16-бенчмарк на GPU 3. После бенчмарка три сида распределяются по отдельным GPU 1/3/2. GPU 2 используется только после проверки свободной памяти и простоя; GPU 0 остаётся сервисам. Если прирост среднего mAP@10 над EXP-003 превышает разброс обоих экспериментов, автоматически следуют претрейн VERI-Wild, три дообучения и суп. Условие в `configs/exp020_clip_vitl14_bot_30ep.yaml`, результат в `EXP-020/status/gate.json`, этап в `EXP-020/status/night_stage`, завершение — `night_DONE` или `night_FAILED`. Задачи отвязаны от SSH.

Первый замер скорости на публичных весах предварительный; после обучения повторяется на seed0 вместе с BNNeck. Весовой файл хранится в fp32, fp16 применяется к вычислениям. Сравнение качества использует неизменённый `evaluate_fold` и `val_v2`. Фолд 4 не используется.

Названия папок, конфигов и чекпоинтов приведены к номерам EXP. Цепочка завершилась 17.09.2026, контроллер вышел, `scripts/pod_names_job.py` удалил временные ссылки. Все восемь чекпоинтов хранятся под именами `exp020_seed0.pt`…`exp024.pt` в `/workspace/checkpoints/`. Сохранённые исходные логи и метрики не переписываются; соответствие прежних имён — `artifacts/EXP-020/name_map.json`. Гиперпараметры и протокол не менялись. Названия закоммичены в `75f0c12`; исходные теги сохраняют первоначальные снимки. Публикация в приватном GitHub теперь разрешена пользователем.

После локального скачивания и проверки sha256 результатов папки EXP-020…024 на поде, общее временное окружение и промежуточные файлы удалены по правилам `AGENTS.md`. Датасеты, публичные веса и все восемь чекпоинтов сохранены; наши процессы завершены. Метрики, AP, эмбеддинги, логи и снимки фактического кода/конфигов/протокола — `artifacts/EXP-NNN/`; квитанции архива и очистки — `artifacts/EXP-020/`.

## Передача результатов и обученная модель
Артефакты EXP-022…024 и веса `exp022_seed0.pt`, `exp024.pt` передаются через [приватный GitHub Release exp-024](https://github.com/chrizantona/yslfalcon/releases/tag/exp-024). В assets есть SHA256SUMS и manifest.json; проверьте их после скачивания. `scripts/github_release_handoff.py` загружает проверенные файлы через Git credential helper, с проверкой SHA256 ответа GitHub. Исходные теги exp-020…024 сохраняются без перезаписи.

`reid.submit` теперь загружает обученный visual encoder вместе с BNNeck. Для EXP-024: `python -m reid.submit --data-config configs/data.yaml --config configs/submit_exp024.yaml`, затем `python -m reid.check_submission` с теми же аргументами. FP16-порог 7,056535 взят с dev-фолда 0 и не подбирается по закрытому тесту. Результат — три файла в `artifacts/EXP-024/submission/`; формат проверяется локальным валидатором, организаторский скрипт пока отсутствует.

Docker подготовлен для текущего обученного EXP-037; проверка Linux amd64 образа идёт, NVIDIA runtime контейнера пока не проверен. Для сборки задайте `GITHUB_TOKEN_FILE` (файл токена за пределами git) и `DATASET_DIR`; GPU задаётся через `INFERENCE_GPU` (по умолчанию 1, можно UUID). `WEIGHTS_URL` уже закреплён на asset API URL exp037.pt (передача в Release завершается). Чтобы контейнер мог записать результаты в bind mount, задайте `INFERENCE_UID` / `INFERENCE_GID` равными значениям `id -u` / `id -g` на хосте (по умолчанию 1000 / 1000). Затем `docker compose up --build`. Токен передаётся BuildKit secret, веса скачиваются при сборке с проверкой SHA256; рабочий инференс не скачивает публичные начальные веса. Версии библиотек закреплены, данные и результаты монтируются отдельно.

EXP-025 завершён: mAP@10 0,834223 (+0,003660), но 95% CI [−0,001421; +0,008791] пересекает ноль — `inconclusive`, TTA не принято. H200 FP16 с TTA: 26,32 мс, 332,2 FPS. Это качество FP32; FP16-качество TTA отдельно пока не проверено. Архив и 143 файла сверены по SHA256.
